# 功能介绍

本篇介绍当前 Aqara Life App 的主要使用流程和默认版界面能力。

## 登录并进入 Studio 空间

用户完成注册登录后，可选择需要访问的 Studio。该 Studio 需要预先在平台端完成云端连接，并绑定至当前登录账号。APP 内选择后，用户即可进入对应的 Studio 空间。

后续迭代可支持直接通过 Aqara Life App 添加新的 Studio，为用户提供更完整的 Studio 管理能力。

## 默认版界面的控件

进入 Studio 空间后，默认版界面主要包含以下 4 种功能控件，暂时只支持首页 Tab 对控件的增删与布局。后续可以拓展到更多插件素材和多页 Tab 的编辑能力，也欢迎开发者一起共创更多插件资源，拓宽想象空间。

### AI Agent 对话框

AI Agent 提供对话式的空间交互入口。用户可以通过自然语言与空间进行交互，实现基础的设备级和空间级查询、控制及编辑能力。

在具备更完整空间信息和配置能力的场景下，AI Agent 可结合空间中的设备及其关系理解用户意图，为用户提供更高级更自然的智能空间交互方式。

### 空间总计

空间总计用于查看当前 Studio 空间的总览数据，包括空间、设备以及已有的场景和自动化，点击后分别可以跳转到对应的详情页面。

- 空间：完整的空间层级脉络树状图。
- 设备：设备列表，按设备所属空间层级为分组进行展示，点击设备名称后可以进入对应设备详情页。
- 场景：特指 Flow 之中“手动触发”的逻辑块，点击后可以执行对应的自动化。
- 自动化：除场景之外的 Flow，支持启用或禁用某条 Flow。

### 常用场景

默认展示前 4 个场景，点击可以执行。点击【常用场景】标题可以查看全部场景。在平台端可以配置这个控件的布局，支持展示 2 行/3 行/4 行。如果对应的 Flow 有所属房间，场景卡片上还会展示对应的房间注释，方便区分和辨别。

### 自动化

默认展示前 4 个 Flow。在平台端可以配置这个控件的布局，支持展示 2 个/4 个/6 个/8 个。如果对应的 Flow 有所属房间，自动化卡片上还会展示对应的房间注释，方便区分和辨别。

## 消息中心与设备告警

平台端预先在告警中心配置设备告警，当设备触发相关事件时，Aqara Life App 的消息中心可以接收对应的推送信息。

当 App 处于远程访问状态时，还支持通过手机系统通知栏向用户发送相关通知，用户无需持续打开 App，也能够及时获知重要设备告警事件。

## 设备详情页

用户可在设备列表页点击设备名称进入对应的设备详情页，对当前设备进行查看和操作。每款设备的能力不同，取决于设备类型及其在 Studio 中提供的能力。
