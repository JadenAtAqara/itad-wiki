# 概览

Aqara Life App 是一款专为 Aqara Studio 产品体系中的终端用户（主要是家庭及 DIY 用户）打造的移动应用。其核心定位是将已经完成配置的空间方案、设备能力和智能服务，以更轻量、直观的方式交付给终端用户，用户可通过直观的 UI 界面或 AI Agent 实现日常的设备控制、场景联动等交互。

后续还将面向 B 端商业地产类项目的运维用户、负责实施运维的安装者等用户提供 Aqara Space App。

## Aqara Life 在 Studio 体系中的定位

在当前使用模式下，用户需要具备支持 Aqara Studio 的边端中枢，并预先在平台端完成 Studio 的云端连接及账号绑定。用户登录 Aqara Life App 后，可选择已绑定的 Studio，并访问对应的 Studio 空间进行日常使用。后续迭代可支持通过 App 添加新的 Studio，让使用流程更加完整。

高阶的空间配置主要在 Aqara Builder 或 Studio 平台完成，Aqara Life App 则聚焦于空间运行、设备与场景使用、信息触达以及面向终端用户的智能交互。

## Aqara Life 的核心能力

| **能力** | **说明** |
| --- | --- |
| 运行 | 加载已经定义好的空间方案，让一个配置完成的空间应用真正运行起来。 |
| 渲染 | 在平台端可根据不同空间类型、用户角色可进行 app 界面配置，app 呈现相应的界面视图与控件。 |
| 连接 | 连接 Studio 能力、设备状态及插件引擎，使不同系统能力能够在 App 中被调用和呈现。 |
| 体验 | 通过 App 界面及 AI Agent，将复杂的系统结构转化为更自然、更易用的日常使用方式。 |

## 面向终端用户的使用模式

Aqara Life App 主要服务于两类使用情形：

- 由服务商完成 Studio 空间方案设计、配置与实施后，由业主及家庭成员使用 Aqara Life App 进行日常控制和空间管理。
- 用户自行购置了具备 Studio 能力的中枢或硬件设备，在平台端完成空间配置后，使用 Aqara Life App。

对于已有 Aqara Home App 使用经验的用户，原有设备也可根据产品实际支持情况，通过重新入网到 Studio 的形式迁移至使用 Aqara Life。但更建议在后续支持了“Aqara Home 数据迁移”能力后再投入使用，现阶段 Aqara Life 更适用于全新用户。
