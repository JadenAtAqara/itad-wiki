# 创建空间方案：户型、结构、保存与导出

本篇目标：建立可继续布置设备的户型，并保存为可重开的空间方案。


## 开始前先掌握：选对象、移视角和结束操作

本节按现有编辑器实现核对，补充容易影响操作的细节；新增快捷键尚未逐项在正式站实测。快捷键取决于当前工具、选中对象和输入焦点。下文 **Cmd / Ctrl** 分别对应 Mac 的 Command 与 Windows 的 Ctrl。

### 对象重叠，总是选错怎么办？

例如灯具与家具、房间与楼板在平面上重叠时：

1. 切到 **2D 平面图**，退出正在放置、移动或绘制的操作，使用选择工具。
2. 若已经选中门窗或壁装设备，先在空白处单击，清除当前选择。
3. 将鼠标停在需要选择的重叠位置，观察预选高亮。
4. **保持鼠标停在该位置，按 Tab 在候选对象之间切换；Shift＋Tab 反向切换。**
5. 目标对象高亮后再单击，正式选中；检查属性面板或空间树中的名称，然后修改。

**预选高亮用于提示将要选到谁，单击后才成为实际选择。** 移动鼠标到另一位置会改变候选对象。该轮换针对平面图拾取，不将它当作所有 3D 视图的通用快捷键。

如果按 Tab 后光标在按钮或输入框之间跳动，先退出输入框、菜单或弹窗，再把鼠标移回画布。当前位置只有一个可选对象时，不会发生候选轮换。仍不好选时，可直接从空间树按名称选择目标。

**注意 Tab 的另一用途：**&#x5355;独选中门、窗或适用的壁装设备后，Tab 可能用于翻转其所在墙面朝向。想切换重叠对象时，先清空选择；想调整墙面朝向时，先明确选中目标。

### 想移动视角，却拖动了设备怎么办？

| 想做什么   | 怎样操作                | 应看到什么             |
| ------ | ------------------- | ----------------- |
| 平移画面   | 鼠标中键拖动；或按住空格再左键拖动   | 空间整体在屏幕内移动，对象位置不变 |
| 持续平移   | 按 H 切到手形工具，再拖动      | 后续拖动用于移动视角        |
| 回到选择   | 按 V，或点选择工具          | 可以再次选择、编辑对象       |
| 缩放     | 在画布内滚动滚轮，或使用视图缩放按钮  | 查看范围改变，对象实际尺寸不变   |
| 旋转观察角度 | 在支持轨道观察的 3D 模式中右键拖动 | 观察方向变化，对象不旋转      |
| 模型跑出视野 | 使用视图工具中的适配 / 总览入口   | 整体空间重新进入视野        |

右键旋转视角与“Cmd / Ctrl＋右键拖动旋转对象”是不同操作。先松开修饰键，再调整视角。漫游模式使用其自身控件，不能直接套用上述轨道观察方式。

### 怎样多选，而不是反复只选中最后一个？

- **逐个增减选择：**&#x9009;择模式下按住 Cmd / Ctrl 单击对象；在画布中也可用 Shift 单击增减选择。
- **一次框选：**&#x32;D 选择模式下，从空白处按住左键拖出选框，再检查实际选中范围。
- **空间树连续选择：**&#x5148;单击起始项，再按 Shift 单击末项，会选中两者之间当前可见的列表项。它与画布中的 Shift 单击行为不同。
- **清空选择：**&#x5728;空白处单击。若正在执行工具操作，先结束当前操作。

修改或删除前查看高亮及空间树，确认没有多选到不想处理的墙、家具或设备。

### 怎么结束当前工具？Esc 为什么有时要按两次？

| 当前情况                      | 操作与反馈                                                      |
| ------------------------- | ---------------------------------------------------------- |
| 2D 墙体、围栏或灯轨正在拉出下一段        | 第一次 Esc 取消当前未落定的线段，保留已完成线段，通常仍在该工具中；没有进行中的草稿后再按 Esc，回到选择模式 |
| 2D 楼板、天花或区域已经放置至少 3 个有效顶点 | Esc 可能按已落定顶点完成当前轮廓；Enter 也可用于提交有效轮廓。不是一律丢弃草稿               |
| 上述多边形只有 1～2 个顶点           | Esc 清除未成形草稿，仍可继续使用工具                                       |
| 菜单、弹窗或属性输入框打开             | Esc 优先由当前界面处理，可能关闭菜单或取消字段编辑                                |
| 当前没有进行中的动作                | 使用选择工具或 V 回到选择状态；观察当前工具高亮后再继续                              |

轮廓无效、与已有区域冲突时，提交可能被拒绝，应先查看提示、修正顶点。若刚完成了不想要的轮廓，确认结果后撤销，不要连续盲按 Esc。

### 编辑数值和改错，怎样确认生效？

1. 先核对选中对象名称，再单击对应数值输入尺寸或位置，留意字段单位。
2. 常用属性输入框按 **Enter** 提交；**Esc** 可取消当前字段的未提交编辑。不同专用面板以自身提示为准。
3. 点击画布前先确认输入完成。光标仍在文本框或 Agent 中时，字母键、删除键等通常用于文字编辑，不执行画布操作。
4. 拖动调整不够精确时，改用属性数值。支持拖动标签的数值控件可横向拖动；其中部分控件支持 Shift 粗调、Alt 细调。
5. 误操作后使用 **Cmd / Ctrl＋Z** 撤销，**Cmd / Ctrl＋Shift＋Z** 重做。正在拖动或绘制时，第一次撤销可能先取消当前动作，应观察结果再决定下一步。
6. 完成一个阶段后保存；使用 **Save** 或当前编辑器支持的 **Cmd / Ctrl＋S**，等待反馈，避免连续重复提交。

### 经常要用的操作速查

| 用户任务         | 操作                                | 使用条件                                      |
| ------------ | --------------------------------- | ----------------------------------------- |
| 在重叠对象中切换预选   | Tab / Shift＋Tab                   | 平面图中鼠标下有多个候选，未在输入、放置或移动中；留意壁装对象的 Tab 翻转行为 |
| 选择 / 手形 / 测量 | V / H / M                         | 画布上下文中；测量需当前阶段开放                          |
| 删除对象         | Delete / Backspace                | 先确认实际选择，光标不在文本框中                          |
| 复制、粘贴对象      | Cmd / Ctrl＋C、Cmd / Ctrl＋V         | 可编辑方案中选择对象；有文字选区时复制优先处理文字。粘贴后检查楼层、位置和引用   |
| 撤销 / 重做      | Cmd / Ctrl＋Z / Cmd / Ctrl＋Shift＋Z | 检查是否先取消了当前进行中的动作                          |
| 保存设计         | Cmd / Ctrl＋S                      | 编辑器保存入口可用，等待完成反馈                          |
| 切换当前建筑的楼层    | Cmd / Ctrl＋↑ / ↓                  | 当前建筑中存在对应楼层                               |

更多上下文快捷键可从编辑器设置中的“键盘快捷键”查看。需要先记住的是：**选谁 → 当前是什么工具 → 操作后看什么反馈 → 确认后保存。**

## 创建、打开和管理方案

### 从空白或示例开始

1. 在项目进入 **Space Plans**。
2. 选择 **Start from Scratch（从零开始）** 或 **Start with Example（从示例开始）**；已有方案时可用 **New Space Plan**。
3. 填写方案名称、摘要后创建，进入编辑器。

### 搜索、复制、改名与删除

在方案列表搜索并打开目标方案。卡片 **More actions（更多）** 中可按开放情况使用 **Edit info**、**Duplicate**、**Scene Builder**、**Deploy**、**Delete**。

复制后先核对副本名称与内容再编辑；删除前核对项目和方案名称。复制、删除及部分信息管理仅核对过入口，提交结果需在相应环境验证。

## 导入户型资料

### 户型图片与比例校准

1. 打开户型底图或导入入口，选择当前支持的图片格式。
2. 在底图中选取已知长度，填写实际尺寸，完成比例校准。
3. 用墙体和房间工具描绘主要结构，检查整体尺寸。
4. 使用 AI 图片优化、识别建模入口时，检查识别后的墙、门窗、房间和比例，再继续布点。

### 外部数据与已有方案文件

代码已有 DXF、RoomPlan 等外部数据转换及场景数据处理。使用时先核对当前版本的上传入口、文件格式和转换提示，导入后检查楼层、单位、边界及位置。具体格式支持范围仍需目标环境验证。

### 从模板开始

在已开放的模板选择入口预览并应用模板，检查它使用的房间、设备与场景后继续编辑。保存模板时使用清晰名称，复用前核对模板来源和适用内容。

## 绘制户型与建筑结构

### 认识编辑区域

空间画布用于编辑；空间树用于查找对象；结构工具用于墙、门窗等绘制；家具、家电和设备分类用于放置资源；选中对象后查看可编辑属性。

<img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-builder/zh/07-floorplan.png" alt="2D 编辑器、空间树与资源分类" style={{ width: '70%' }} />

### 绘制墙体与矩形墙

**先分清点选与连续绘制：**&#x77E9;形墙用两个对角点确定范围；连续墙逐段确定端点，完成一段后可能仍在等待下一段。画完一间房后检查工具是否仍激活，需要时用 Esc 结束当前线段、再退出工具。

1. 切到 **2D**，打开 **Structure tools**。
2. 连续墙按起点、终点绘制；矩形墙按两个对角点建立轮廓。
3. 选中墙体检查位置、长度和连接关系，按属性面板开放内容修改。
4. 删除或移动墙体前，检查附着的门窗、开关等对象。

<img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-builder/zh/44-rectangle-wall.png" alt="矩形墙绘制后出现房间、墙体和楼板" style={{ width: '70%' }} />

### 添加门窗、房间和功能区

| 对象         | 操作方法                     | 完成后核对             |
| ---------- | ------------------------ | ----------------- |
| 门 / 窗 / 开口 | 选择对应工具或资源，放到目标墙体，调整位置与尺寸 | 附着墙体正确，尺寸与开口合理    |
| 房间         | 检查闭合墙体生成的房间，或使用当前开放的绘制入口 | 名称、用途及边界正确        |
| 功能区        | 在房间内划分实际使用区域并命名          | 能区分客厅中的沙发区、用餐区等范围 |
| 楼板 / 天花    | 检查自动生成内容，按可编辑属性调整        | 范围与房间、楼层一致        |
| 楼梯 / 柱等结构件 | 选择结构资源，放置后编辑位置和尺寸        | 与上下楼层及墙体关系合理      |

### 管理楼栋与楼层

用编辑器楼栋、楼层入口创建、命名和切换层级；逐层检查结构与设备归属。跨层查看时注意当前编辑楼层，避免在错误楼层布点。

## 家具、家电、材质与对象编辑

1. 从 **Furniture / Appliances** 选择资源，添加到房间。
2. 选中对象，调整位置、方向和可编辑的尺寸。
3. 按对象支持的墙面、地面、顶面等位置放置，检查门窗开启、家具碰撞和空间尺度。
4. 在材质入口选择材质，对支持的表面应用并核对效果。
5. 用空间树选择、定位、复制或删除对象；编辑失误时使用撤销、重做，确认结果后保存。

## 保存、版本与导出

### 保存并重新打开

1. 点 **Save**，等待页面返回结果。
2. 返回列表重新打开，核对结构、房间、家具和点位。
3. 打开 **Version History** 检查记录；实测示例方案保存后出现 `Version 1`。

<img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-builder/zh/10-version-history.png" alt="版本历史面板" style={{ width: '70%' }} />

### 查看与恢复历史

选择历史记录，先核对时间与预览内容，再使用页面提供的恢复操作。恢复后重新检查方案和保存记录，确认后再用于后续部署。

### 导出图纸、清单与模型

| 产物              | 使用目的         | 导出后检查            |
| --------------- | ------------ | ---------------- |
| 平面图 / 点位与安装 PDF | 沟通空间、布点和安装信息 | 图纸范围、设备编号、尺寸及清晰度 |
| 设备清单            | 核对所需型号与数量    | 型号、数量、房间和点位      |
| 场景 JSON / 3D 模型 | 保存或交换设计数据    | 当前版本支持的格式及内容是否完整 |

导出后检查文件格式与内容。保存过程会生成部分相关产物，是否另有下载入口以当前页面为准。
