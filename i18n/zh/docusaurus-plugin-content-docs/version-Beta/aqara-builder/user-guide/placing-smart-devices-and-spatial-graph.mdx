# 布置智能设备，构建空间图谱

本篇目标：把设备放到正确位置，建立明确的房间归属、供电和控制关系。

## 查找设备与使用已有设备

### 从设备库选型

1. 打开 **Devices（设备）**，按分类或搜索查找资源。
2. 核对型号、名称和可用信息，区分同一产品的不同型号。
3. 查看设备能力时，检查属性、命令、事件与端点；具体支持动作以型号能力结果为准。

### 使用 AI 设备建议

先打开目标方案，在 Agent 中说明房间用途、希望的体验和已有设备；检查推荐型号、所需能力与数量。推荐结果进入方案后仍应核对实际点位和保存结果。

### 从 Studio 导入设备

在当前版本开放的设备导入或关联入口连接 Studio，获取设备列表后选择需要使用的设备，检查型号与房间归属，再布置或关联方案点位。旧版“从我的设备创建”的位置已变化，当前请从目标方案的 Studio 关联与设备入口查找。

## 放置、命名与调整设备

**先选中，再移动。**&#x753B;布出现预选高亮时先单击确认对象；重叠时按[创建空间方案](creating-space-plans.mdx)的 Tab 方法选择。检查属性面板显示的名称后，再修改位置或参数。

1. 将目标设备添加到画布。
2. 放到正确房间和安装面，设置位置、方向、高度及其他开放属性。
3. 按“房间＋位置或用途”命名，例如“客厅－沙发右侧落地灯”。
4. 切换 2D / 3D 检查实际位置、朝向及房间归属，再保存。

| 设备或资源      | 重点检查               |
| ---------- | ------------------ |
| 墙面开关       | 墙面位置、安装高度、按键数、控制对象 |
| 顶面灯具 / 轨道灯 | 所属顶面或轨道、方向、数量与间距   |
| 传感器 / 摄像机  | 朝向、遮挡、安装位置与可用覆盖示意  |
| 门窗设备       | 对应门窗和安装方向          |
| 自由放置设备     | 实际家具或地面位置、空间归属     |

### 移动、旋转和整体调整

| 你遇到的情况      | 建议操作                                        | 操作后检查                           |
| ----------- | ------------------------------------------- | ------------------------------- |
| 单个家具或设备需要移动 | 使用选中对象的移动控件；3D 中支持的对象可在单选后按 Cmd / Ctrl＋左键拖动 | 房间、位置和安装面没有改变成意外对象              |
| 单个对象需要精细旋转  | 使用旋转控件；3D 中适用对象可按 Cmd / Ctrl＋右键左右拖动         | 默认角度吸附是否符合需要；该拖动中加 Shift 可自由旋转  |
| 需要快速转向      | 对适用家具或设备使用 R / T 逐步反向旋转                     | 门窗的 R / T 有开向、墙面等专用行为，不当作普通家具旋转 |
| 多件家具要一起移动   | 先多选，拖动选区或虚线框；也可单击拾起，再单击放下                   | 移动的是整组，组内相对位置保持预期               |
| 多选对象要一起转向   | 在支持的多选状态使用 R / T，绕组中心分步旋转                   | 组中心与整组位置是否合理                    |

### 设备“放不下”“放反面”时先查什么？

1. 资源是否要求墙面、地面、顶面、门窗或轨道安装？先找到正确的安装载体。
2. 当前楼层和视图是否正确？切到 2D 或 3D 交叉检查，不要只凭图标重叠判断高度。
3. 壁装设备是否附着在墙的另一侧？退出放置后单独选中，按当前支持的 Tab 翻面操作调整，再检查墙面与朝向。
4. 是否仍在“拿着对象”的移动状态？确认放置后再选其他对象，避免连续拖动改变原位置。
5. 对象存在但被遮住时，从空间树选择或调整视角；设备名称相似时先核对房间和型号。

## 配置照明与开关关系

### 灯轨与轨道灯

绘制轨道并检查路径，在对应轨道添加适用灯具，调整数量、位置和方向。检查灯具是否附着正确轨道，以及是否与顶面、其他结构冲突。

### 灯带与驱动

1. 选择灯带资源，按安装路径绘制。
2. 调整路径和长度，核对墙体、天花及家具关系。
3. 按配置入口选择适用驱动，检查长度与驱动配置后保存。

测试时曾遇到驱动资源不可用；资源无法加载时先核对型号与服务提示，完成驱动配置后再继续验证效果。

### 开关与受控设备

1. 放置开关，核对按键数量。
2. 选中开关，打开控制设备或对应配置入口。
3. 选择按键和受控设备，逐键配置。
4. 检查设备类型、控制对象及供电关系，保存后再次打开核对。

旧版说明中的同类型受控设备限制、重复选择规则，需要以当前配置面板的实际限制为准。普通负载经智能开关供电时，应明确真实执行动作的开关。

### 覆盖范围辅助查看

打开传感器、摄像机、灯光或 Wi-Fi 对应的覆盖显示，结合房间、家具与朝向调整位置。覆盖图用于辅助设计，实际范围仍要结合设备和现场验证。

## 空间图谱：让 AI 理解关系

### 图谱记录哪些信息

| 关系        | 示例                | 有什么用           |
| --------- | ----------------- | -------------- |
| 空间与空间     | 客厅包含沙发区、餐区        | 理解具体生活范围       |
| 设备与空间     | 落地灯位于客厅沙发区        | 找到正确设备，避免跨房间误选 |
| 设备与设备     | 落地灯由智能开关供电        | 确定真实控制对象       |
| 关系与设备能力结合 | 开关支持通断，灯具支持相应调光能力 | 按可用能力生成场景动作    |

### 设计师怎样准备图谱所需信息

1. 补齐房间名称、用途与功能区。
2. 核对设备点位、房间归属和型号。
3. 配置开关、负载等设备关系。
4. 保存方案，再进入依赖空间图谱的 Agent 场景创作或部署操作。

已有保存流程会尝试生成空间图谱；**户型保存成功后，图谱仍可能沿用上一次成功版本**。修改了房间或设备而 Agent 仍使用旧内容时，先重新保存并核对图谱相关提示与实际读取结果。

### 一个具体例子

需求：“离家时关闭客厅落地灯。”AI 先定位客厅与灯，识别供电开关，再查询开关可执行能力，形成待核对的动作。自动化的触发与条件需要在场景设计中明确。
