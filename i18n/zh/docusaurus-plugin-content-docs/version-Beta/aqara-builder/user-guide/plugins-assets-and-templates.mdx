# 插件、资产与模板

本篇目标：检查可用资源、为 Studio 配置插件，并了解账号权益与使用偏好。


## 浏览与获取插件

1. 进入 **Plugins**，使用分类或搜索找到插件。
2. 打开详情，核对适用端、版本、说明和更新记录。
3. 在 **Get Plugin** 等获取入口检查资格、数量及页面要求，确认后按流程办理。
4. 返回资产列表核对获取结果。

## 我的资产与分配

1. 打开当前环境的 **My Assets（我的资产）**。
2. 查看 **Available to assign（可分配）**、**Assigned（已分配）**、**Expired（已过期）**。
3. 对可分配插件点 **Assign**，选择项目和 Studio，检查数量与对象。
4. 按流程提交后，检查数量变化、分配记录及目标 Studio 的使用结果。

*已查看分配弹窗，未提交；资产数量与目标结果仍需实际验证。*

## 发现与复用模板

在方案或应用工作台开放的模板、市场入口查看资源，确认适用类型后复用。复用空间模板时检查房间和设备，复用界面时检查页面和数据绑定；保存到正确项目后再继续修改。
