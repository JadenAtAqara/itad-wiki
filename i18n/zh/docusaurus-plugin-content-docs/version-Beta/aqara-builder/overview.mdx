# 概述

## 什么是 Builder？

Builder 是一套面向全屋智能内容发现、方案创作、实施和管理的产品组合，由 Community、Builder Lab 和 Studio Manager 组成。

无论你是希望打造全屋智能空间、创作自己的设计方案，还是将现有方案部署到实际项目，Builder 都可以提供相应的工具。

## Community、Builder Lab 和 Studio Manager 分别能做什么？

| 产品 | 能做什么 |
| --- | --- |
| Community | 发现和浏览全屋智能内容，了解不同空间的设计思路 |
| Builder Lab | 创作空间规划、场景与自动化及界面设计，并将设计部署到 Studio |
| Studio Manager | 管理项目、Studio、Studio 成员、资源、历史信息及成员使用的界面 |

三个产品可以独立使用，也可以相互配合。你可以从 Community 获得灵感，在 Builder Lab 完成设计，再通过 Studio Manager 管理实际项目。

## 想打造全屋智能空间，Builder 如何帮你开始？

你可以先在 Community 了解全屋智能内容和设计思路，再使用 Builder Lab 从零创建自己的空间规划。

如果已经有 Aqara Studio 和智能设备，也可以将 Studio 的子设备同步到 Builder Lab，在现有设备基础上继续完成设计。

## 想创作自己的全屋智能方案，Builder 提供了哪些工具？

Builder Lab 提供空间规划和界面设计两类创作工具。

在空间规划中，你可以绘制户型、布置家具和智能设备、配置灯带和开关控制关系，并设计场景与自动化。在界面设计中，你可以为 Studio 成员创作可查看和操作的应用界面。

## 已有全屋智能方案，如何通过 Builder 部署和管理？

空间方案可以部署到 Studio。部署前，Builder 会将方案设备与 Studio 中的实际设备进行匹配。

界面设计可以部署给指定的 Studio 成员。部署后，可以在 Studio Manager 中查看和调整成员当前使用的界面，并管理相关项目、Studio、成员、资源和历史。

## 空间规划和界面设计有什么区别？

空间规划负责户型、家具、设备点位、场景和自动化，部署对象是 Studio。部署空间方案前，需要完成方案设备与 Studio 实际设备的匹配。

界面设计负责用户看到和操作的应用界面，部署对象是 Studio 中的具体成员。部署界面设计不需要设备匹配，但需要先在 Studio Manager 中建立 Studio 成员。

空间规划和界面设计是两个独立模块，可以分别创作和部署。
