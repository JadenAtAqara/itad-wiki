# 概述

## 什么是 Builder？

Builder 是一套面向全屋智能内容发现、方案创作、实施和管理的产品组合，由 **社区**、**Builder 工坊** 和 **Studio 站点管理** 组成。

无论你是希望打造全屋智能空间、创作自己的设计方案，还是将现有方案部署到实际项目，Builder 都可以提供相应的工具。

## 社区、Builder 工坊和 Studio 站点管理分别能做什么？

| 产品 | 能做什么 |
| --- | --- |
| **社区** | 发现和浏览全屋智能内容，了解不同空间的设计思路。<img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-builder/zh/Builder-Community.png" alt="Builder 社区" />  |
| **Builder 工坊** | 创作空间规划、场景与自动化及界面设计，并将设计部署到 Studio。<img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-builder/zh/Builder-Lab.png" alt="Builder 工坊" />  |
| **Studio 站点管理** | 管理项目、Studio、Studio 成员、资源、历史信息及成员使用的界面。<img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-builder/zh/Builder-StudioManager.png" alt="Builder Studio 站点管理" />  |

三个产品可以独立使用，也可以相互配合。你可以从 **社区** 获得灵感，在 **Builder 工坊** 完成设计，再通过 **Studio 站点管理** 管理实际项目。

## 想打造全屋智能空间，Builder 如何帮你开始？

你可以先在 **社区** 了解全屋智能内容和设计思路，再使用 **Builder 工坊** 从零创建自己的空间规划。

如果已经有 Aqara Studio 和智能设备，也可以将 Studio 的子设备同步到 **Builder 工坊**，在现有设备基础上继续完成设计。

## 想创作自己的全屋智能方案，Builder 提供了哪些工具？

**Builder 工坊** 提供空间规划和界面设计两类创作工具。

在空间规划中，你可以绘制户型、布置家具和智能设备、配置灯带和开关控制关系，并设计场景与自动化。在界面设计中，你可以为 Studio 成员创作可查看和操作的应用界面。

## 已有全屋智能方案，如何通过 Builder 部署和管理？

空间方案可以部署到 Studio。部署前，**Builder** 会将方案设备与 Studio 中的实际设备进行匹配。

界面设计可以部署给指定的 Studio 成员。部署后，可以在 **Studio 站点管理** 中查看和调整成员当前使用的界面，并管理相关项目、Studio、成员、资源和历史。

## 空间规划和界面设计有什么区别？

空间规划负责户型、家具、设备点位、场景和自动化，部署对象是 Studio。部署空间方案前，需要完成方案设备与 **Studio** 实际设备的匹配。

界面设计负责用户看到和操作的应用界面，部署对象是 Studio 中的具体成员。部署界面设计不需要设备匹配，但需要先在 **Studio 站点管理** 中建立 Studio 成员。

空间规划和界面设计是两个独立模块，可以分别创作和部署。
