# 场景 vs 自动化：核心区别

这是 Builder Agent 里最容易混淆的概念。下面用一张对比表讲清楚：

## 对比表

| | **场景** | **自动化** |
|---|---|---|
| **执行方式** | 主动执行（人触发）| 被动执行（条件触发）|
| **触发来源** | 用户手动一键 / 语音唤起 | 系统检测到条件满足时自动触发 |
| **典型例子** | 「晚安模式」点一下，全屋关灯关窗调空调 | 「温度>28°C 且有人 → 自动开空调」|
| **适用场景** | 用户知道自己要什么，一键搞定 | 环境变化需要自动响应，不需要人操心 |
| **代表功能** | 晚安模式、观影模式、出门模式、晨起模式 | 人走灯灭、温度调控、安防布防、光照感应开灯 |

## 什么时候用场景，什么时候用自动化

**用场景**：
- 用户明确知道想要什么动作组合
- 需要一键完成多个设备的协同控制
- 场景相对固定，用户手动唤起

**用自动化**：
- 需要根据环境状态自动响应
- 条件复杂，需要「当 X 满足且 Y 满足时才执行」
- 用户不想操心，系统自动代劳

:::tip
场景和自动化不是二选一，而是配合使用。一个完整的智能家居方案，通常既有「一键触发」的场景（晚安模式），也有「自动响应」的自动化（人走灯灭）。Builder Agent 可以同时生成场景和自动化，组合出完整的智能体验。
:::
