# 空间解析（基础能力）

空间解析是 Builder Agent 的 **地基**：在推荐设备、编排场景之前，Agent 必须先「看懂」这个空间。

## 为什么它是地基

设备推荐要知道「哪个房间放什么设备」，场景编排要知道「客厅的灯和空调怎么联动」——这些都依赖一个前提：**Agent 清楚空间里有什么、东西在哪、彼此什么关系**。

空间解析就是把「一张户型图 / 一段描述」变成 Agent 能计算的 **空间语义模型**。

## 它怎么工作

整体分三步：

1. **矢量化**：把户型图片转成可计算的几何图形（墙、门、窗、房间轮廓）
2. **本体化**：把几何图形映射成空间语义（这是客厅、那是主卧、这是阳台……）
3. **关系建模**：建立房间 / 设备 / 区域之间的连接关系

## 空间模型长什么样

解析完成后，空间会被表示成一张 **语义图谱**：

- **节点（nodes）**：房间、设备、区域等
- **关系（edges）**：属于（belongsTo）、连接（connects）、相邻（isAdjacentTo）等

例如：「客厅温度传感器」通过 belongsTo 关系归属于「客厅」节点，Agent 后续推荐和编排都基于这张图来判断。

## 点面判断与设备归属

有了空间模型，Agent 能做两件关键事：

- **设备归属房间**：判断某台设备属于哪个房间（用于推荐和编排的上下文）
- **点位坐标**：确定设备在空间里的具体位置（xyz），用于安装落位

:::tip
空间解析的质量直接决定后续效果。户型越清晰、信息越完整，推荐和编排就越准。建议在建方案时优先上传完整户型图。
:::
