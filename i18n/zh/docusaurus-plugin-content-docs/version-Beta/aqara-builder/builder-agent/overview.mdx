# Builder Agent 概述

Builder Agent 是 Aqara Builder 平台里的 **AI 方案设计助手**：帮服务商把客户的一句话空间需求，变成一份可直接部署的空间智能方案。

## 它解决什么问题

传统空间智能方案靠专家人工设计：

- **设计慢**：一个户型要反复沟通、画图、列设备
- **质量不稳**：依赖个人经验，不同人做出来的方案差距大
- **容易漏项**：漏设备、漏场景，客户体验不一致

Builder Agent 把这件事变成「说需求 → 出方案」，服务商把精力放在客户沟通和落地上。

## 三大核心能力

Builder Agent 围绕空间方案设计，提供三个 Agent：

| Agent | 它做什么 |
|---|---|
| **设备推荐 Agent** | 你说需求，它给你一份带理由的设备清单，并指出还缺什么 |
| **场景生成 Agent** | 把「晚安模式」「观影时刻」这类一键场景编排出来 |
| **自动化生成 Agent** | 把「人走灯灭」「温度太高开空调」这类条件触发规则生成出来 |

## 典型工作流

一次完整的方案设计，通常走这几步：

1. **创建方案 / 上传户型**：告诉 Builder Agent 你的空间长什么样
2. **户型图识别**：上传户型图，Agent 完成空间解析，理解每个房间和已有设备
3. **激活 Agent**：根据需要，唤起设备推荐 / 场景生成 / 自动化生成 Agent
4. **生成方案包**：三个 Agent 协作输出完整的设备清单 + 场景 + 自动化规则
5. **一键部署**：方案包推送至 Aqara Studio，安装人员即可使用

![图14：最终方案包生成及部署](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-builder/zh/agent-image-14-final-solution-package-generation-and-deployment.png)

:::tip
空间解析是一切能力的地基。户型理解得越准，后面推荐和编排就越准。设备推荐 Agent 是第一个上场的 Agent，通常在户型图识别完成后第一个启动。
:::
