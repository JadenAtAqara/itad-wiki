# 部署界面设计

界面设计部署给 Studio 中的具体成员，不需要进行设备匹配。

## 部署前确认成员

开始部署前，先在 Studio Manager 中邀请并管理目标 Studio 的成员。只有已经加入 Studio 的成员，才能在界面设计部署时被选择。

如果成员尚未加入 Studio，请先阅读《管理 Studio 成员》。

## 选择 Studio 和成员

1. 在 Builder Lab 中打开需要部署的 UI。
2. 进入部署操作。
3. 选择目标 Studio。
4. 选择一个或多个需要使用该 UI 的 Studio 成员。
5. 核对 UI、Studio 和成员。
6. 确认部署。

## 部署给错误成员时如何处理

如果 UI 部署给了错误成员，请前往 Studio Manager，在成员界面管理中修改该成员当前使用的 UI。
