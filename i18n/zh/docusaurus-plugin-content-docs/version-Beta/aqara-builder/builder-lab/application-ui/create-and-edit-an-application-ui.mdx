# 创建和编辑界面设计

应用界面用于组织 Studio 成员可以看到和操作的应用界面。它与空间规划相互独立，可以单独创建和部署。

<img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-builder/zh/ApplicationUI-DesignApp.png" alt="创建应用界面" />

## 创建界面设计

1. 打开 Builder 工坊 的界面设计功能。
2. 创建或打开 UI 方案。
3. 创建一套 UI。
4. 从空白界面或官方模板开始设计。

## 编辑界面

在界面编辑器中，可以：

- 添加和配置功能组件。
- 调整组件内容和界面布局。
- 创建和管理多个界面。
- 设置界面之间的跳转关系。
- 预览和保存 UI。

操作步骤：

1. 打开需要编辑的 UI。
2. 创建或选择界面。
3. 添加需要的功能组件。
4. 调整组件内容和布局。
5. 根据需要创建其他界面并设置跳转。
6. 预览并保存 UI。
