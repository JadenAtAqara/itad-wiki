# Builder Lab 常见问题

## Builder Lab 中找不到本地 Studio

**可能原因**：打开 Builder Lab 的设备与 Studio 不在同一局域网。

**处理方法**：将设备与 Studio 连接到同一局域网，再重新查找本地 Studio。

## Builder Lab 中找不到本地 Studio

**可能原因**：Studio 尚未完成初始化。

**处理方法**：先完成 Studio 初始化，再返回 Builder Lab 查找 Studio。

## “从我的设备创建”时没有找到需要的 Studio

**可能原因**：当前选择的云端或本地连接方式不正确。

**处理方法**：根据 Studio 的实际连接方式，重新选择云端 Studio 或本地 Studio。

## 空间方案无法继续部署

**可能原因**：仍有方案设备没有匹配 Studio 实际设备。

**处理方法**：找到未匹配设备，为每个方案设备选择一个 Studio 实际设备。

## 自动匹配结果与现场设备不符

**可能原因**：自动匹配结果需要人工确认。

**处理方法**：手动修改方案设备与 Studio 实际设备的匹配关系。

## 设备已完成匹配，但功能可能不符合方案要求

**可能原因**：当前系统不限制设备能力兼容性。

**处理方法**：根据设备经验确认方案设备与 Studio 实际设备的能力是否兼容。

## 开关按键无法继续选择另一类设备

**可能原因**：为按键选择第一个受控设备后，前端只允许继续选择同一类型设备。

**处理方法**：根据控制需要，使用同一类型的 Aqara 智能设备或非 Aqara 智能设备。

## 部署界面设计时找不到目标成员

**可能原因**：该成员尚未加入目标 Studio。

**处理方法**：先在 Studio Manager 中邀请成员，并确认成员已经加入 Studio。
