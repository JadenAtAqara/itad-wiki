# 部署空间方案

空间方案部署到 Studio 前，需要将方案设备与 Studio 中的实际设备完成匹配。

<img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-builder/zh/SpacePlan-DeploySpacePlan.png" alt="部署空间方案" />

## 选择目标 Studio

目标 Studio 可以通过云端或本地方式连接。

- 使用云端 Studio 时，确认账号、Region、项目和目标 Studio 正确。
- 使用本地 Studio 时，确认 Studio 已初始化，并且打开 **Builder 工坊** 的设备与 Studio 处于同一局域网。

操作步骤：

1. 打开需要部署的空间规划方案。
2. 进入部署操作。
3. 选择云端 Studio 或本地 Studio。
4. 选择并核对目标 Studio。


<img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-builder/zh/SpacePlan-SelectAStudio.png" alt="选择目标 Studio" />

## 检查自动匹配结果

选择目标 Studio 后，系统会先自动匹配方案设备和 Studio 实际设备。

- 部署回设备来源 Studio 时，系统会自动匹配此前已经部署过的子设备。
- 部署到其他 Studio 时，系统会根据目标 Studio 重新匹配设备。

自动匹配完成后，需要逐项检查结果。如果匹配结果不符合现场情况，可以手动修改。

## 手动修改匹配关系

1. 找到需要调整的方案设备。
2. 查看当前匹配的 Studio 实际设备。
3. 选择其他 Studio 实际设备。
4. 继续处理其他未匹配或错误匹配的设备。

前端不允许同一个 Studio 实际设备被多个方案设备重复匹配。已经匹配的 Studio 实际设备不能再次用于其他方案设备。

<img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-builder/zh/SpacePlan-LinkDevices.png" alt="链接设备" />

## 完成匹配并部署

部署前，请确认：

- 每一个方案设备都已经匹配一个 Studio 实际设备。
- 方案设备与 Studio 实际设备具备符合方案需要的功能能力。

当前系统不会自动限制设备能力兼容性，需要根据设备经验检查匹配是否合理。

确认空间方案、目标 Studio 和匹配结果后，提交部署。

<img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-builder/zh/SpacePlan-ConfirmDeployment.png" alt="确认部署" />
