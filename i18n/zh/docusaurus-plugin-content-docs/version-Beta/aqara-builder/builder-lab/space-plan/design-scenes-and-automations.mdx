# 场景与自动化设计

场景与自动化用于设置设备在特定情况下执行指定动作。

常见内容包括：

- 触发：什么时候开始执行。
- 条件：满足什么条件时才执行。
- 动作：哪些设备执行什么操作。
- 延时：等待一段时间后再执行操作。

## 创建场景或自动化

1. 打开场景与自动化设计功能。
2. 新建场景或自动化。
3. 填写容易识别的名称。
4. 选择触发方式。
5. 根据需要添加条件。
6. 选择设备并设置动作。
7. 检查执行顺序并保存。

如果删除或替换了方案设备，应重新检查引用该设备的场景和自动化。
