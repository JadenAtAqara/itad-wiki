# 场景与自动化设计

场景与自动化用于设置设备在特定情况下执行指定动作。创建和编辑场景与自动化只能通过 Agent 对话完成。

## 通过 Agent 创建场景与自动化

1. 打开场景与自动化设计。
2. 进入 Agent 对话。
3. 用自然语言描述希望实现的场景或自动化效果。
4. 根据需要补充使用的设备、触发条件和执行要求。
5. 完成对话。

Agent 对话完成后，系统会直接生成并保存对应的场景或自动化，不需要再次手动确认或保存。
描述需求时，可以说明：
- 什么情况下开始执行。
- 是否需要满足特定条件。
- 哪些设备需要执行动作。
- 设备需要执行什么动作。

## 查看自动化 Workflow

创建完成后，可以逐个查看自动化的 Workflow。
1. 打开已经创建的场景与自动化列表。
2. 选择需要查看的自动化。
3. 打开对应的 Workflow。
4. 查看触发、条件、设备动作和执行关系。

Workflow 用于查看自动化内容，不能直接在 Workflow 中创建或编辑。需要修改时，应返回 Agent 对话。
