# 布置家具和智能设备

完成主要空间结构后，可以根据实际使用场景布置家具和智能设备。家具可以帮助你判断灯具、开关、传感器和其他设备的位置是否合理。

## 布置家具

1. 打开家具库。
2. 浏览或搜索需要的家具。
3. 将家具添加到画布。
4. 将家具移动到目标空间和位置。
5. 根据需要调整方向和其他属性。
6. 检查家具是否与墙体、门窗或其他对象冲突。

<img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-builder/zh/SpacePlan-AddFurnitures.png" alt="布置家具" />


## 布置智能设备

1. 打开设备库。
2. 查找需要的智能设备。
3. 将设备添加到画布。
4. 将设备布置到合适的空间和位置。
5. 调整方向和其他可编辑属性。

从零创建时，添加到画布的是方案设备。从我的设备创建时，可以使用同步进来的 Studio 子设备进行设计。
