# 创建空间规划方案

空间规划方案用于组织户型、家具、智能设备、场景和自动化设计。创建方案时，可以选择“从零创建”或“从我的设备创建”。

## 从零创建

当你尚未准备实际设备，或希望先完成设计再准备设备时，可以从零创建方案。

1. 打开 Builder Lab。
2. 选择创建空间规划方案。
3. 选择“从零创建”。
4. 填写方案名称等信息。
5. 确认创建并进入空间规划编辑器。

## 从我的设备创建

当你已经拥有 Studio 和子设备时，可以将设备列表同步到编辑器，并基于现有设备进行设计。

可选择以下设备来源：
- 已连接云端并归属于当前账号的 Studio。
- 与当前设备处于同一局域网的本地 Studio。

操作步骤：

1. 打开 Builder Lab。
2. 选择创建空间规划方案。
3. 选择“从我的设备创建”。
4. 选择云端 Studio 或本地 Studio。
5. 查看所选 Studio 的子设备列表。
6. 确认同步设备并创建方案。

使用本地 Studio 前，请确认 Studio 已完成初始化，并且打开 Builder Lab 的设备与 Studio 处于同一局域网。

## 将方案用于其他 Studio

从我的设备创建不会将方案永久绑定到设备来源 Studio。
- 部署回设备来源 Studio 时，系统会自动匹配此前已经部署过的子设备。
- 部署到其他 Studio 时，系统会根据目标 Studio 重新进行设备匹配。
- 自动匹配完成后，可以手动修改匹配关系。
