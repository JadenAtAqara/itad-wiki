# 绘制户型和空间结构

进入空间规划方案后，先完成主要户型和空间结构，再布置家具和智能设备。

## 认识主要操作区域

空间规划编辑器主要包括：
- 空间画布：查看和编辑户型、家具及设备。
- 绘制工具：绘制墙体等空间结构。
- 家具库：查找和添加家具。
- 设备库：查找和添加智能设备。
- 属性区域：调整当前选中对象的位置和参数。
- 视图工具：缩放、移动或切换视图。

<img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-builder/zh/SpacePlan-EditorComponents.png" alt="空间规划编辑器主要操作区域" />

## 绘制墙体

1. 选择墙体绘制工具。
2. 在画布上选择墙体起点。
3. 移动指针并选择墙体终点。
4. 按照户型依次绘制其他墙体。
5. 检查墙体之间的连接和空间边界。
6. 删除墙体前，先检查墙面上是否已经布置门、窗、开关或其他设备，避免影响已布置的对象。
