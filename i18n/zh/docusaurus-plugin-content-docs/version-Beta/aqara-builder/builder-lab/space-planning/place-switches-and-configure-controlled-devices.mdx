# 布置开关并配置控制设备

先将开关布置到合适的位置，再为每个按键选择需要控制的设备。

## 布置开关

1. 打开设备库。
2. 找到需要使用的开关。
3. 将开关添加到空间。
4. 将开关布置到正确的空间和墙面。
5. 检查开关的按键数量是否符合设计需要。

> **待补充截图：** 开关在设备库中的入口及布置到墙面的效果。

## 配置开关控制设备

1. 选择已经布置的开关。
2. 打开“开关控制设备”。
3. 选择需要配置的按键。
4. 为该按键选择一个或多个受控设备。
5. 继续配置其他按键。
6. 检查控制关系并保存。

配置时需要注意：

- 一个按键可以控制多个设备。
- 为按键选择第一个受控设备后，前端只允许继续选择同一类型的设备。
- 如果第一个受控设备是 Aqara 智能设备，后续只能选择 Aqara 智能设备。
- 如果第一个受控设备是非 Aqara 智能设备，后续只能选择非 Aqara 智能设备。
- 同一个受控设备可以被多个按键选择。
