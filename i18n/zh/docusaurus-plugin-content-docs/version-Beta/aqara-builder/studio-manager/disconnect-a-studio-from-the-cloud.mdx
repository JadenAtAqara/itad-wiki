# 云端解绑 Studio

云端解绑会解除 Studio 与云端的连接关系。操作前应确认 Studio 和所属项目，避免解绑错误设备。

1. 进入目标 Studio。
2. 找到云端解绑入口。
3. 核对 Studio 信息。
4. 阅读页面中的影响说明。
5. 按页面要求确认解绑。
6. 检查操作结果。
