# 管理 Studio 成员

Studio 成员可以访问和使用具体 Studio。界面设计需要部署给 Studio 成员，因此部署界面前应先完成成员管理。

## 邀请成员

1. 找到目标 Studio。
2. 打开 Studio 成员管理。
3. 选择邀请成员。
4. 输入目标账号。
5. 选择 Admin 或 Operator。
6. 核对账号、Studio 和角色。
7. 发送邀请。

受邀人可以接受或拒绝邀请。邀请发起方可以撤销尚未生效的邀请。

## 移除成员

1. 在 Studio 成员列表中找到目标成员。
2. 确认成员账号和角色。
3. 选择移除成员。
4. 确认操作。
