# 管理项目

项目用于组织和管理 Studio。每台 Studio 必须属于一个项目。

## 查看项目

1. 打开 Studio Manager。
2. 确认当前账号、Personal Team 和 Region。
3. 打开项目列表。
4. 找到目标项目。
5. 进入项目查看其中的 Studio。

## 新建项目

1. 打开项目列表。
2. 选择新建项目。
3. 填写项目信息。
4. 确认创建。
5. 在列表中检查新项目。

## 编辑项目

1. 找到需要修改的项目。
2. 打开项目编辑操作。
3. 修改页面提供的项目信息。
4. 保存更改。

## 删除项目

Default 项目不能作为普通项目删除。仍包含 Studio 的项目也不能直接删除。

删除普通空项目时：

1. 打开需要删除的项目。
2. 选择删除项目。
3. 核对项目信息和删除提示。
4. 确认删除。
