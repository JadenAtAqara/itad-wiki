# 管理成员使用的界面

界面设计在 Builder 工坊 中创作并部署给 Studio 成员。Studio 站点管理 用于查看和调整成员当前使用的 UI。

## 查看界面使用情况

进入界面管理后，可以查看：

- Studio 当前可用的 UI。
- 每套 UI 当前分配的成员。
- 已分配 UI 的成员。
- 尚未分配 UI 的成员。

## 为成员分配界面

1. 进入 Studio 的界面管理。
2. 选择需要使用的 UI。
3. 打开成员管理。
4. 选择一个或多个目标成员。
5. 检查成员当前使用的 UI。
6. 保存更改。

## 更换或取消成员界面

- 更换 UI 时，重新选择成员需要使用的 UI 并保存。
- 取消分配时，在成员管理中取消选择对应成员并保存。
- 界面部署给错误成员时，在这里修改该成员当前使用的 UI。
