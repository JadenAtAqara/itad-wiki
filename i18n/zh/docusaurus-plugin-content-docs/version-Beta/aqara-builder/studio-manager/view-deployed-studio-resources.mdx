# 查看 Studio 已部署资源

进入 Studio 后，可以通过资源查看相关资源，通过历史查看历史操作和结果。

## 查看资源

1. 进入目标 Studio。
2. 打开资源。
3. 查看当前 Studio 的资源内容。
4. 确认资源名称和项目是否符合预期。

## 查看历史

1. 进入目标 Studio。
2. 打开历史。
3. 找到需要查看的记录。
4. 打开记录查看详情和结果。
