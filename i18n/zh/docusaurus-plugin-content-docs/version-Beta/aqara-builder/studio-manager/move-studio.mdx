# 移动 Studio

Studio Move 用于将 Studio 从当前项目移动到另一个项目。

1. 在 Studio Manager 中找到需要移动的 Studio。
2. 打开 Studio Move。
3. 选择目标项目。
4. 核对当前项目、目标项目和 Studio。
5. 确认移动。
6. 前往目标项目检查 Studio。
