# 概览

Aqara Space App 是一款 **面向 [Aqara Studio](./../aqara-studio/overview/introduction.mdx) 产品体系中的实施人员（installer）** 打造的移动应用，定位为智能空间的现场部署与实施交付工具。其核心定位是承接在平台端在线完成的空间方案，将其高效落地为真实可用的智能空间：实施人员可通过它完成 Studio 连接、设备入网、方案部署、AI 现场调优以及交付验收等现场工作。

与面向终端用户的 **[Aqara Life App](./../aqara-life/overview.mdx)** 相对，**Aqara Space** 服务于智能空间交付链路的前半程——它不是「日常使用」的入口，而是「把方案变成现实」的工具。交付完成后，业主通过 Aqara Life App 进行日常使用，两个应用共同构成从交付到使用的完整链路。

## Aqara Space 在 Studio 体系中的定位

在 Studio 体系中，空间方案由设计师与创作者在 **[Aqara Builder](./../aqara-builder/overview.mdx)** 平台在线创作完成，项目与工单由业务系统进行管理；Aqara Space 负责现场的勘查、安装、部署与交付实施。

高阶的空间配置主要在 Aqara Builder 或 Studio 平台完成，Aqara Space 则聚焦于方案的现场落地：连接现场环境与设备、将方案精准部署到 Studio、对部署结果进行调优，并推动项目完成验收交付。

## Aqara Space 的核心能力

| 能力 | 说明                                                                                              |
| -- | ----------------------------------------------------------------------------------------------- |
| 获取 | 登录后获取名下负责实施的工单与项目，随时查看方案概要与布局设计，实施前对项目了然于心。                                                     |
| 连接 | 自动发现并连接同一局域网内的 Studio 边缘主机，支持静态 IP 配置以适配各类现场网络环境。<br />支持 Thread、Matter、BLE 等多种协议的智能设备便捷入网并接入 Studio。 |
| 部署 | 将方案设备与真实设备进行精准关联，可通过设备查找快速定位实体设备。<br />全部关联成功后一键部署到 Studio，让线上设计的方案快速落地为真实空间。                         |
| 调优 | 通过 AI Agent 以自然语言调整场景与自动化、智能排障，对部署结果进行现场微调，保障交付质量。                                              |
| 交付 | 通过自检与验收功能完成实施检查与交付验收。                                                                           |

## 面向实施人员的使用模式

Aqara Space App 的典型使用情形如下：
- 服务商的安装人员在接到项目后，使用 Aqara Space 获取名下工单与项目信息，到达现场后连接 Studio、完成设备入网与方案部署，并通过自检与验收功能完成实施检查与交付验收。
