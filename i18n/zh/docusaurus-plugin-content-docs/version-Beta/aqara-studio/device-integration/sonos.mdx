# Sonos 设备接入

本文说明如何将 Sonos 设备接入 Aqara Studio。

## 前提条件

在开始之前，请确保您已使用 [Sonos App](https://support.sonos.com/zh-cn/downloads) 将 Sonos 设备成功连接到 Aqara Studio 所在的局域网。

## 安装插件

请参考 [插件市场](./../plugin-center.mdx) 文档：
1. 前往 [Aqara Builder](https://builder.aqara.com) 获取 `Sonos Protocol Access` 插件。
2. 将其分配到 Aqara Studio。
3. 并前往 Aqara Studio 的 **插件中心** 安装该插件。

## 添加 Sonos 设备

1. 在左侧侧边栏点击进入**设备管理**页面。在左侧 **协议和设备** 单击 **...** 按钮，选择 **添加协议**。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/Devices-AddProtocol.png" alt="添加协议" /> 

2. 在弹窗中选择 `Sonos Access`。   
    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/Protocols-ChooseSonosAccess.png" alt="选择 Sonos Access" style={{ width: '60%' }} /> 

3. 在左侧侧边栏选择 `Sonos Access`，单击 `添加设备` 按钮。

    ![发现设备](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/Sonos-ClickAddDevice.png)

    在弹窗中选择 **自动发现**，并单击 **开始接入设备**。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/Sonos-SelectAutoDiscovery.png" alt="选择自动发现" style={{ width: '60%' }} />

 
4. 单击“发现设备”按钮，Aqara Studio 即开始扫描网络发现设备。  

    ![Discover Devices](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/Sonos-ClickDiscoverDevices.png)

5. 选择需接入的设备后，点击中间“+”按钮。

    新增设备会出现在右侧的已添加设备列表。单击 **完成** 按钮，退出添加设备流程。

6. 此时，您将在左侧 **协议和设备** 的 Sonos Access 节点下，以及该 Sonos Access 管理页面的设备列表中，看到已成功添加的设备。
