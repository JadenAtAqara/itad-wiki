# Home Assistant 生态集成

Aqara Studio 支持将 Home Assistant 生态的物联网设备接入。目前仅支持 [符合 Aqara 设备规范的功能类型](#支持的设备类型)。

## 前提条件

在开始之前，请确保：
- Home Assistant 生态设备、电脑以及 Aqara Studio 已连接至同一局域网。
- 已完成以下 Home Assistant 基础配置：
  - Home Assistant 系统安装，详情请参考 Home Assistant 官网文档 [Installation](https://www.home-assistant.io/installation/)。
  - Home Assistant 生态设备发现与集成，详情请参考 Home Assistant 官网文档 [Onboarding](https://www.home-assistant.io/getting-started/onboarding/)。
  
## 获取 Home Assistant Token

1. 在浏览器地址栏中输入访问此地址：`http://homeassistant.local:8123`（如果您修改过 Home Assistant 的端口号，请修改本地址的端口号后再访问），访问 Home Assistant 主页。
2. 单击右下角您的账号，进入 profile 页面。
3. 在 profile 页面，点击“安全”标签，找到“长期访问令牌”，单击“创造令牌”，即可生成 Home Assistant Token，用于在 Aqara Studio 上 [添加 Home Assistant 生态设备](#添加-home-assistant-生态设备)。

<img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/HAIntegration-CreateHAToken.png" alt="创建 Home Assistant Token" />

## 添加 Home Assistant 生态设备

1. 在左侧侧边栏点击进入**设备管理**页面。在左侧 **协议和设备** 单击 **...** 按钮，选择 **添加协议**。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/Devices-AddProtocol.png" alt="添加协议" /> 

2. 在弹窗中选择 `Home Assistant`，以添加 `Home Assistant`。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/Protocols-ChooseHomeAssistant.png" alt="选择 Home Assistant" style={{ width: '60%' }} /> 

3. 在左侧 **协议和设备** 树选择新增的 `Home Assistant`，单击其 **协议配置** 按钮。

  <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/HomeAssistant-ClickProtocolConfiguration.png" alt="单击协议配置按钮" /> 

4. 在 **基础配置** 中输入 Home Assistant 系统的本地 IP 地址、端口和 [令牌](#获取-home-assistant-token)。

  <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/HomeAssistant-FillInBasicConfiguration.png" alt="输入 Home Assistant 基础配置" style={{ width: '60%' }} /> 

5. 在 `Home Assistant` 协议管理页面中单击 **添加设备** 按钮。

  <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/HomeAssistant-ClickAddDevice.png" alt="单击添加设备按钮" /> 

6. 单击 **发现设备** 按钮，本系统即可自动发现 Home Assistant 中的设备。

  ![发现设备](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/HomeAssistant-ClickDiscoverDevices.png)


7. 选择需接入的设备，单击中间的 **+** 按钮。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/HomeAssistant-SelectDevicesAndClickPlus.png" alt="新增发现设备" /> 

    新增设备会出现在右侧的已添加设备列表。单击 **完成** 按钮，退出添加设备流程。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/HomeAssistant-AddedDeviceList.png" alt="已添加设备列表" /> 

8. 此时，您将在左侧 **协议和设备** 的 Home Assistant 节点下，以及该 Home Assistant 管理页面的设备列表中，看到已成功添加的设备。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/HomeAssistant-CheckAddedDevices.png" alt="设备已添加至 Home Assistant 下" /> 


   
## 支持的设备类型

- Light
- Media Player
- Vacuum
- Switch
- Climate
- Select
- Binary Sensor
- Lock
- Sensor
  - FlowSensor
  - AirQualitySensor
  - TemperatureSensor
  - PressureSensor
  - ParticulateMatterSensor (PM1，PM2.5，PM10)
  - IlluminanceSensor
  - HumiditySensor
  - NaturalGasAlarm
  - CO2Sensor
  - AtmosphericPressureSensor
