# Aqara RS-485 设备接入

本文说明如何将 Aqara RS-485 设备接入 Aqara Studio。

## 什么是 Aqara RS-485 

**Aqara RS-485** 是 Aqara 面向有线智能化场景推出的私有 RS-485 通信协议，主要用于支持 RS-485 接口设备通过标准化的有线总线方式接入 Aqara Studio 本地化平台。

基于 Aqara 私有 RS-485 协议，相关设备可实现稳定可靠的数据上报、状态同步、参数配置及自动化联动，从而满足酒店、公寓、办公楼、商业空间等项目型场景中对高可靠性、集中管理和本地化控制的需求。

## 有线 / 无线 / 有线+无线方案优势对比

通过 Aqara RS-485 协议接入后，Aqara 可在原有 Zigbee、Thread、Wi-Fi 等无线设备体系基础上，进一步扩展 RS-485 有线设备接入能力，形成“有线 + 无线”融合的本地化智能控制方案。

## 前提条件

在开始之前，请确保：
- 您的 Aqara 配电箱网关（例如 [AX100M](./../product-knowledge/gateways/din-rail-hub-ax100m.mdx)）、智慧边端（例如 M300/GX300M） 和 电脑处于同一局域网中；
- 您的 Aqara 配电箱网关已接入到智慧边端的 Aqara Studio 中，详情请参考 [Aqara Hub 设备接入](./aqara.mdx)。
- 您已将 Aqara RS-485 设备（例如 AW110K）接入 Aqara 配电箱网关 RS485 接口。如需了解接线方式，请参考相关设备的电子说明书，或咨询技术支持。

## 流程

1. 在左侧侧边栏点击**设备管理**，选择 `Aqara RS-485` 进入管理页面，点击**添加设备**按钮。

    ![添加 Aqara RS-485 设备](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/AqaraRS485-AddDevice.png)

2. 在页面中，选择 Aqara Hub 网关（需已与待接入的 Aqara RS-485 设备相连），选择 **实时入网** 或 **定时入网**，单击 **开启入网** 按钮，Aqara Studio 会将 Aqara RS-485 设备接入 Aqara Studio。

    ![选择 Aqara Hub 网关并开启入网](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/AqaraRS485-SelectGatewayAndEnableNetworkAccess.png)

    入网成功后，Aqara RS-485 设备会出现在左侧 **已添加设备**列表中，单击 **完成** 按钮，退出添加设备流程。

3. 此时，您将在左侧 **协议和设备** 的 Aqara RS-485 节点下，以及该 Aqara RS-485 管理页面的设备列表中，看到已成功添加的设备。

    ![Aqara RS-485 设备添加成功](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/AqaraRS485-CheckAddedDevices.png)
