# 远程访问

## 功能概览

默认情况下，您只能在局域网内访问 Aqara Studio。当需要通过外部网络进行连接时，您可以使用**远程访问**，以便从任意位置安全地管理您的智能家居设备和控制系统。

## 前提条件

在开始使用远程访问之前，请确保您已 [连接了 Aqara Cloud](./cloud.mdx)。

## 访问流程

1. 访问 [Aqara Builder](https://builder.aqara.com) 官网，从左边侧边栏进入 **Builder 工坊**。

    ![进入 Builder 工坊](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/PluginCenter-EnterBuilderLab.png)

2. 在顶部导航栏选择您的头像，在下拉列表中选择 **Studio Manager**。

    ![选择 Studio Manager](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/RemoteAccess-EnterStudioManager.png)

3. 选择您在 [云端连接](./cloud.mdx) 时登录 Aqara 账号所选的 **区域**。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/RemoteAccess-SelectARegion.png" alt="选择区域" style={{width: "60%"}} />

4. 进入 Studio Manager 后，切换至 **Studio** 标签页。在其下单击一个你想要远程访问的 Aqara Studio。

    ![连接 Aqara Studio](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/RemoteAccess-SwitchToStudiosAndSelectAStudio.png)

5. 在弹窗中单击 **控制台**，即可通过远程访问该 Aqara Studio。当需要通过外部网络进行连接时，您可以使用

    ![单击控制台按钮](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/RemoteAccess-ClickConsole.png)

    ![Aqara Studio 远程访问控制台](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/RemoteAccess-RealAccess.png)

    :::tip
    您还可以使用现有的本地用户账号登录该远程访问地址，所拥有的权限与在本地访问时完全一致，详情请参考 [本地用户管理 - 本地用户角色](./user.mdx#本地用户角色)。
    :::

## 分享给其他 Aqara 用户

如需将邀请其他 Aqara 用户远程访问您的 Aqara Studio，请遵循如下流程：

1. 进入 Studio Manager 后，切换至 **Studio** 标签页。在其下单击一个你想要远程访问的 Aqara Studio。

    ![连接 Aqara Studio](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/RemoteAccess-SwitchToStudiosAndSelectAStudio.png)

2. 在弹窗中单击 **分享** 按钮。

    ![单击分享按钮](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/RemoteAccess-ClickShare.png)

3. 在弹窗中选择受邀用户将会被分配的角色，以及此邀请链接的有效期。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/RemoteAccess-SelectARoleAndExpirationDate.png" alt="选择角色和过期日期" style={{width: "60%"}} />

4. 单击 **复制** 按钮，即可将此链接分享给其他 Aqara 用户。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/RemoteAccess-CopyTheLink.png" alt="复制链接" style={{width: "60%"}} />
  
5. 当受邀用户点击此链接后，会看到一个申请访问的页面，需点击 **申请** 按钮。

    ![申请访问](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/RemoteAccess-Request.png)

6. 此时，您需要在 Studio Manager 再次点击该 Studio 详情，查看 **Studio 成员**，找到此申请，点击 **批准** 按钮。

    ![申请访问](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/RemoteAccess-ApproveRequest.png)

7. 此时，此受邀用户即可在 **Studio Manager > Studio** 标签页下看到该 Aqara Studio，并可以进行远程访问，详情请参考 [访问流程](#访问流程)。

## 远程用户角色

远程用户，是指使用 Aqara Builder 账号访问 Aqara Studio 的用户。远程用户的角色可分为管理员（admin）或操作员（operator）。
