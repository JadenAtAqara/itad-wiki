# 本地固件库

Aqara Studio 支持用户在无网络环境下，通过本地手动导入固件文件，实现 Aqara Studio 系统版本更新，以及网关（Aqara）和子设备（Aqara）固件的升级。

## 前提条件

操作前，请确保已通过 Aqara 技术支持获取所需固件文件，并已将其保存至本地电脑。

:::tip
请和 Aqara 技术支持确认文件名称符合 Aqara Studio 文件命名校验规则。
:::

## 上传本地固件

1. 在左侧导航栏点击 **设置**，进入设置页面后，选择侧边栏中的 **本地固件库** 选项。单击 **上传固件** 按钮。
    ![上传固件](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/LocalFirmwareLibrary-ClickUpload.png)
2. 在弹窗中选择固件文件，选择目标固件文件。
3. 随后，您会看到一个上传进度弹窗。当上传进度条为 100% 后，Aqara Studio 会提示固件文件上传成功。
    ![上传进度](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/LocalFirmwareLibrary-UploadProgress.png)
