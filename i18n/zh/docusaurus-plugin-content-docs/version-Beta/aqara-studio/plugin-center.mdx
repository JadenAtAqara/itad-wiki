# 插件中心

Aqara Studio 支持通过 [Aqara Builder](https://builder.aqara.com) 获取并安装插件，拓展 Aqara Studio 的功能。插件市场中的插件由 Aqara 官方提供，也可以由用户自行开发上传。

## 前提条件

在开始之前，请确保您已实现 [云端连接](./cloud.mdx)。

## 获取插件

1. 访问 [Aqara Builder](https://builder.aqara.com) 官网，从左边侧边栏进入 **Builder 工坊**。

    ![进入 Builder 工坊](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/PluginCenter-EnterBuilderLab.png)

2. 从左边侧边栏进入 **市场**，即可浏览各种插件。点击希望获取的插件，进入其详情页。

    ![进入市场](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/PluginCenter-EnterMarket.png)

3. 选择 **获取插件** 按钮，**确认**了解安装须知并**确认**订单后，即可成功获取。

    ![获取插件](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/PluginCenter-GetAPlugin.png)

3. 从左边侧边栏进入 **资产**，即可看到已获取的插件。
    
    单击 **分配** 按钮，弹出配置弹窗。

    ![分配插件](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/PluginCenter-Assets.png)

4. 在配置弹窗中，选择对应的区域、空间和需安装插件的 Aqara Studio，确认无误后点击 **确认**，即可将插件成功分配到指定的 Aqara Studio。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/PluginCenter-SelectStudio.png" alt="Select Studio" style={{ width: '60%', height: 'auto' }} />

## 安装插件

1. 访问您的 Aqara Studio，从左边侧边栏进入 **插件中心** 页面。

2. 找到您刚分配的插件，单击 **安装** 按钮，即可开始安装。安装完成之后，可以使用该插件包含的能力。

![点击安装按钮](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/PluginCenter-Install.png)
