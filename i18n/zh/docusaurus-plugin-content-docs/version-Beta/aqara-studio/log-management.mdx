# 日志管理

在侧边栏选择**日志审计**，可访问以下七类日志，为系统运维与安全审计提供了详尽的数据支持：

- [设备日志](#设备日志)
- [网关运行日志](#网关运行日志)
- [链路日志](#链路日志)
- [用户操作日志](#用户操作日志)
- [插件日志](#插件日志)
- [系统升级日志](#系统升级日志)
- [固件升级日志](#固件升级日志)

所有日志均支持时间筛选和关键词搜索，满足日常运维与审计需求。

:::tip
Aqara Studio 默认显示当天 00:00:00-23:59:59 的日志。如需查看历史日志，请手动选择查询的时间范围。
:::

## 设备日志

您可查看全部设备的功能点值的变更记录，并可依设备 ID、设备名称和功能点名称进行筛选。

## 链路日志

您可查看 Aqara Studio 与各协议的链路通道（如 Aqara Cloud-M300、Studio Connect-BACnet IP）是否正常（最近 500 条），并可依链路名称进行筛选。

## 用户操作日志

您可查看用户登录、功能使用等所有操作记录（最近 500 条），并可依用户名称进行筛选。

## 插件日志

您可以查看 Aqara Studio 插件相关的所有操作日志，涵盖操作时间、插件名称、类型、版本、插件 ID、用户名及操作内容等信息。日志支持按类型、操作内容（如下载安装、卸载、更新等操作成功与否）等条件筛选和展示，便于回溯插件使用历史和进行运维分析。

## 系统升级日志

您可以查看系统更新的时间、版本号及更新结果，便于追溯升级历史和排查问题。

## 固件升级日志

您可以查看通过 Aqara Studio 进行的 Aqara 设备固件升级操作，包括升级时间、设备 ID、设备名称、升级版本及升级结果，便于全面追溯和分析设备固件的更新历史。
