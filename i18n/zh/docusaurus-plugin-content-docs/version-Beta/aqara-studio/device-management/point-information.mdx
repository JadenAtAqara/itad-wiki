# 查看和控制功能点（Trait）

本文将介绍如何在 Aqara Studio 中查看和操作设备的功能点（Trait）。您可以读取功能点的实时状态，并通过写入功能点字段来控制设备。

:::tip
Trait 描述设备的一个属性或状态，支持 Read、Write、Report 等操作。

与 Command 的区别：Trait 支持 Read、Write、Report 等操作，而 Command 只是命令，不存在状态。
:::

## 操作

进入**设备管理**页面，在左侧 **协议和设备** 树中选择你想要查看的设备，以查看该设备的管理页面，您将看到一个功能点列表。

![查看功能点标签页](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/Points-CheckPoints.png)

每个功能点代表该设备的一个字段或状态。您可以从该列表获取功能点的以下字段：

| 字段       | 说明                         |
|------------|------------------------------|
| 功能点名称 | 功能点的显示名称，默认与 `系统名称` 相同，可根据需要修改。 |
| 系统名称 | 功能点的系统标识名称，不可编辑。 |
| 功能点类型 | 功能点所归属的类别。该字段的可编辑性会因设备协议的不同而有所区别：<ul><li> Modbus TCP 设备：可编辑。</li><li>其他：不可编辑。</li></ul> |
| 最近值     | 功能点最新的实时数值。         |
| 操作 | 您可以对功能点执行以下操作：<ul><li><strong>功能点详情</strong>：查看基础信息、控制功能点、查看历史数据等。</li><li><strong>复制</strong>：复制该功能点。</li><li><strong>获取最新值</strong>：立即刷新并获取最新数值。</li><li><strong>删除</strong>：删除该功能点。</li></ul>**注意**：根据设备协议类型，部分功能点可能不支持上述全部操作。 |
| 控制       | 针对**可写**功能点，您可以在此处直接设置字段或执行开关等操作，配置成功后`最近值`将自动更新为最新状态。 |
