# 展示历史数据

在 Aqara Studio 设备管理中，您可以便捷地查询和分析设备功能点的历史数据。通过设置采集规则，系统将自动记录并展示设备某一功能点在不同时刻的状态变化，帮助您跟踪运行趋势、发现异常或优化设备配置。下文将介绍如何配置与查看历史数据。

## 操作步骤

1. 进入**设备管理**页面，在左侧 **协议和设备** 树中选择你想要查看的设备，以查看该设备的管理页面，您将看到一个功能点列表。

    ![查看功能点标签页](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/Points-CheckPoints.png)

2. 找到您想要查看的功能点，呼出 **操作** 菜单，选择 **功能点详情**。

    ![呼出操作菜单](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/History-ClickPointDetail.png)

3. 在 **功能点详情** 弹窗中，向下滚动至 **历史数据** 区域，配置 **采集策略**。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/History-FindHistoryAndAdjustCollectionPolicy.png" alt="找到历史数据并调整采集策略" style={{ width: '60%' }} />

4. 定义时间范围，下方会自动生成历史数据图表，您即可查看该功能点在指定时间范围内的运行趋势。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/History-DefineTimeRange.png" alt="定义时间范围" style={{ width: '60%' }}  />
