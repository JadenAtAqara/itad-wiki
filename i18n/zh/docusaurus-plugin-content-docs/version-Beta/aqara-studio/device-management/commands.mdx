# 通过指令（Command）控制设备

本文将介绍如何在 Aqara Studio 中通过指令（Command）控制设备。 

:::tip
Command 描述一个可执行的操作。

与 Trait 的区别：Trait 支持 Read、Write、Report 等操作，而 Command 只是命令，不存在状态。
:::

## 操作步骤 

1. 进入**设备管理**页面，在左侧 **协议和设备** 树中选择你想要查看的设备，以查看该设备的管理页面，点击 **更多设置**。

    ![单击“更多设置”按钮](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/BasicInfo-ClickMoreSettings.png)

2. 在 **更多设置** 弹窗中，向下滚动至 **指令控制（Command）** 区域，即可查看该设备支持的指令。通过指令中的各类组件，即可对设备进行控制。

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/Commands-FindCommandControl.png" alt="找到指令控制" style={{width: '60%'}} />
