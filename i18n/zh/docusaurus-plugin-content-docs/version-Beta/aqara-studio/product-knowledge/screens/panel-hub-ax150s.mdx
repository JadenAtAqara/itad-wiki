## 产品概述

Aqara 妙控场景屏 AX150S 是一款专为 B 端客户设计的场景触控面板，搭配 Aqara Studio 平台使用。基于标准 86 底盒安装，可快速替换传统墙壁开关。采用全新物模型方案（非点值方案），支持本地配网无需依赖云端，通过 Studio 逻辑功能块灵活配置屏端设备、场景和待机内容。

产品支持多底座兼容（PoE 网口底座、开关底座），内置 Zigbee 网关功能和温湿度传感器。支持 Zigbee 和 Thread 双协议，具备 Matter Controller、Thread Border Router 功能，可将绑定的 Zigbee 子设备连接至第三方 Matter 生态。支持 2.4GHz 和 5GHz 双频 Wi-Fi 6 无线联网。屏幕上最多支持 12 个页面，支持自定义屏保和壁纸。

以场景应用触控面板为入口，实现设备的联动控制，同时具备未来的软件和硬件的定制拓展性。支持触屏近距离控制和APP远程操作。

## 安装说明

### 安装条件确认

安装位置：传统开关处内嵌墙安装（标准 86 底盒），需要零火线供电。

禁止安装于高湿环境（洗手间、厨房等）。

安装工具：螺丝刀（用于接线端子螺丝）。

配件：安装螺丝 x 2。

### 安装注意事项

安装前请确认电源总闸已关闭！请在设备断电状态下接线，避免发生电气事故。

#### PoE 底座版安装

1. 关闭供电总电源开关；
2. 用螺丝刀松开背面端子螺丝，将火线接入 L 端子，零线接入 N 端子；
3. 将网线插入 PoE/LAN 端口；
4. 确认接线正确后拧紧端子螺丝；
5. 使用提供的螺丝将底座固定到墙壁接线盒上（螺丝扭矩不超过0.7 N*m）；
6. 将屏幕面板安装到底座上。

#### 开关底座版安装

1. 关闭供电总电源开关；
2. 用螺丝刀松开背面端子螺丝，将火线接入L端子，零线接入N端子；
3. 确认接线正确后拧紧端子螺丝；
4. 使用提供的螺丝将底座固定到墙壁接线盒上（螺丝扭矩不超过0.7 N*m）；
5. 将屏幕面板安装到底座上。

:::tip
参考线色：火线通常为红色，零线通常为蓝色或黑色。
:::

## 使用说明

### 快速设置

#### 1. 上电并等待启动

接通电源后，设备自动开机，屏幕正常显示并进入入网（配对）提示页面。

#### 2. 添加到 Aqara Studio

##### PoE 底座版

PoE 底座版支持通过 Studio 或 Aqara Life 入网：

- Studio 入网（推荐）： 确保 M300 与 AX150S 在同一局域网下。PoE 底座网线连接路由器后，在 Studio Web 页面的 Aqara Hub 中点击"添加设备"，发现设备后导入并添加，详情请参考 [Aqara Hub 接入](./../../device-integration/aqara.mdx)。
- Aqara Life 入网： 打开 Aqara Life APP -> 点击“登录”页面底部的“Studio 模式” -> 添加新的 Studio（手动输入IP地址或域名）-> 登录 Studio -> 按引导完成设备添加。

##### 开关底座版

开关底座版支持通过 Aqara Life 入网：
- 打开 Aqara Life APP -> 点击"登录“页面底部的"Studio 模式” -> 添加新的 Studio -> 登录 -> 按引导完成设备添加。

#### 3. 从 Studio 配置屏端内容

设备入网后，通过 Studio Web 页面配置设备卡片、场景、待机画面等内容，点击"发布"后屏上显示对应画面。

## 排障指引

### 如何解决入网失败？

- 请确认 AX150S 和 Studio设备（比如：M300） 在同一局域网下；
- 请确认设备固件和 Studio 均为最新版本；
- PoE 底座版请检查网线是否正常连接路由器；
- 检查路由器是否开启 Wi-Fi 防蹭设置，导致设备无法正常联网；
- 检查路由器是否开启 AP 隔离，导致手机在局域网内无法搜索到设备；
- 建议不要连接桥接网络；

:::tip
如设备10分钟内未完成入网，AP和蓝牙入网方式将被禁用，需点击屏幕上的刷新按钮或重新上电以重新进入可配置状态。
:::

### 如何恢复出厂设置？

屏幕上下滑进入系统设置菜单，进入系统设置页面按提示操作恢复出厂设置。恢复出厂设置将清除所有功能设置和网络数据。

## 常见问题FAQ

### AX150S 和 AX100S 的主要区别是什么？

AX150S 是 AX100S 的升级版，主控升级为 SSD 2351Q，DDR 256MB，增加了温湿度传感器，支持更多底座类型，配置平台从 Aqara Home 迁移到 Studio，采用新物模型方案。

### 为什么从 Aqara Home 迁移到 Aqara Studio？

Aqara Studio 是面向 B 端的专业配置平台，提供更灵活的新物模型、本地配置、逻辑功能块等能力，更适合 B 端客户的专业需求。

### 可以从 Aqara Studio 配置什么信息到屏上？

可以配置场景和设备、AX150S设置项、多种待机、已设计待机等。部分功能支持批量配置。

### 局域网控制的具体范围是？

无外网时，在局域网内 AX150S 及其下面的设备可跨网关控制设备及场景。

### 语音助手支持情况？

AX150S 设备本身不支持语音助手（无麦克风），扬声器为蜂鸣器。

### 屏幕上最多可以支持多少个页面？

最多可以支持12个页面。

### PoE 底座版和开关底座版在入网方式上有什么区别？

PoE 底座版支持通过 Studio 直接入网（网线连接后自动发现）和 Aqara Life 入网两种方式；开关底座版仅支持通过 Aqara Life 入网。

### AX150S 支持哪些设备类型的卡片？

目前已支持灯类、开关类、窗帘类（开合帘）、空调类、温湿度传感器、场景、能耗卡片。后续优先支持插座、卷帘等设备。
