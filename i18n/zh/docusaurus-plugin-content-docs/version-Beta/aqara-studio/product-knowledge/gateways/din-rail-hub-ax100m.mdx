## 产品概述

Aqara 配电箱网关 AX100M 是 Aqara 推出的一款符合配电箱 DIN 导轨安装规范的网关产品，支持安装在标准 DIN 导轨上使用。支持 Zigbee 和 Thread 双协议，支持 Matter Controller 和 Thread Border Router 功能，可以 Matter Bridge 身份将绑定的 Zigbee 子设备连接第三方 Matter 生态。支持连接 Aqara RS-485 子设备，通过 RS485 有线连接实现对 Modbus 子设备的入网配网和控制管理。支持 2.4GHz 和 5GHz 双频 Wi-Fi 无线联网，支持 USB Type-C和电源模块两种供电方式。

## 安装说明

### 安装条件确认

安装工具：连接线（建议使用双绞线或AWG 28电子线，需自行准备）。

### 安装注意事项

- 安装前请确认电源总闸已关闭！请在网关断电状态下接线，避免发生电气事故。
- 请搭配 Aqara 专用电源模块使用。该电源模块的电压输出为 24V，能够连接 Aqara 配电箱网关 AX100M 和 Aqara RS-485 子设备的 DC 端口提供电源。如需搭配其他电源模块使用，请安装前与Aqara技术支持确认规格，避免损坏。

## 使用说明

### 快速设置

#### 1.选择供电方式并安装

本产品支持使用 [电源模块](#电源模块通过-dc-端口供电) 或 [Type-C](#通过type-c供电) 两种供电方式。

:::warning
安装前请确认电源总闸已关闭！请在网关断电状态下接线。
:::

##### 电源模块通过 DC 端口供电
1.关闭供电总电源开关；
2.将网关的DC接口插上所适配的端母；
3.将网关的V+和V-端口分别与电源模块输出端的V+和V-用连接线相连；
4.将总电线接入电源模块输入端，打开供电总电源即可供电。

###### 通过Type-C供电

使用5V⎓1A电源适配器，搭配USB Type-C电源线，连接电源适配器和网关的Type-C进行供电（配件不包含电源线和电源适配器）。

#### 2.网关天线安装

由于网关的安装环境，配电箱会屏蔽网关的 Zigbee 和 Thread 信号，需要搭配包装盒内附带的天线使用。将天线的 SMA 接口拧入网关上的 SMA 接口，并将天线安装在配电箱外，即可实现网关对配电箱外的 Zigbee 和 Thread 子设备进行信号通信。

#### 3.等待网关启动

网关指示灯从黄灯常亮变成黄灯快闪。

#### 4.网关绑定

将配电箱网关 AX100M 接入路由器，与 M300 处于同一局域网，登陆 M300 Aqara Studio管理页面，详见 [Aqara Hub 入网指引](./../../device-integration/aqara.mdx)。

### 按键说明

| 操作方式             | 功能说明                                           |
|----------------------|--------------------------------------------------|
| 长按功能键 10 秒以上    | 恢复网络参数（用户的配置数据不发生改变）；防误删模式开启时，无法从设备端解绑，需在Studio上删除设备。 |
| 快按功能键 10 次        | 恢复出厂设置（清除所有用户数据至出厂状态）。        |
| 快按功能键 3 次         | 进入添加 Zigbee 子设备状态。                         |

### 指示灯说明

| 指示灯状态     | 功能说明 |
| ------------ | ------------------------------------------------------------------------------------------- |
| 黄灯常亮       | 正在启动。                           |
| 黄灯快闪       | 等待连接网络。                         |
| 蓝灯快闪       | 连接网络中。                         |
| 蓝灯慢闪       | 网络连接成功，账户绑定中。                         |

| 白灯常亮       | 启动 10 分钟，未配置网络                         |

### 主要能力

- 支持本地配网到 M300 的 Aqara Studio，可脱离云端 AIOT 使用。
- 可作为 Zigbee 网关和 Thread Border Router，连接 Aqara Zigbee 和 Thread 子设备。
- 可作为 Matter Bridge，将绑定的 Aqara Zigbee 子设备接入第三方 Matter 生态。
- 支持 Matter Controller，接入第三方 Matter 设备。
- 通过 RS485 接口有线连接 Aqara RS-485 子设备（支持连接 32 个 Aqara RS-485 子设备），提供配网连接和控制能力。
- 支持 2.4G & 5GHz 双频 Wi-Fi 6 无线联网，以及 RJ45 有线联网。
- 可接入第三方 Matter 平台（Google、Alexa、三星 SmartThings 等）。

## 排障指引

### 故障现象及可能的原因与解决方案

常见入网失败：
- 请通电后长按网关按键 10 秒以上，待黄灯闪烁后，重试添加；
- 检查路由器是否开启 Wi-Fi 防蹭设置，导致网关无法正常联网；
- 检查路由器是否开启 AP 隔离，导致手机在局域网内无法搜索到网关；
- 建议不要连接桥接网络。

## 常见问题

### 配电箱网关AX100M是否支持第三方 RS-485 协议，例如 Modbus RTU、BACnet MS/TP 等？

目前不支持。

### 有线协议 RS-485 相比无线协议 Zigbee & Thread 的优缺点？

RS-485 简单可靠，一旦部署几乎无需维护，但需要前装部署，新增设备较困难。
