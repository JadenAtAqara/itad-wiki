## 产品概述

Aqara 智慧网关 AX200M 是网关 M200 的 B 端版本（Nand Flash由 128MB 升级为 256MB），面向企业级用户与系统集成商，可作为 extension hub 搭配网关 M300 扩展控制范围。支持连接 Aqara Zigbee 和 Thread 设备，支持 2.4/5GHz 双频 Wi-Fi 6；支持 Type-C 与 PoE 双重供电；支持本地配网到 M300 的 Aqara Studio，可脱离云端 AIOT使用；支持 Matter Controller / Thread Border Router，以及将 Zigbee 子设备 Matter Bridge 至第三方Matter 生态；支持自定义铃声与个性化联动语音播报；支持连接B端专供子设备。

## 使用说明

### 快速设置

#### 1.选择供电方式

本产品支持使用 [Type-C](#type-c-供电) 或 [PoE](#poe-供电) 两种供电方式。

##### Type-C 供电

使用 5V⎓2A 电源适配器，搭配 USB Type-C 电源线，连接电源适配器和网关的Type-C接口进行供电。

##### PoE 供电
使用支持IEEE 802.3af的PoE设备，通过RJ45网线为网关供电（48V⎓0.25A）。

#### 2.等待网关启动

网关指示灯黄灯长亮，完成启动后进入黄灯快闪（等待连接）。

#### 3.网关绑定

有线连接入网：将智慧网关 AX200M 通过网线接入路由器/交换机，与 M300 处于同一局域网，登录 Aqara Studio 管理页面完成入网（详见 [Aqara Hub 入网指引](./../../device-integration/aqara.mdx)）。

## 产品功能

### 接口说明

| 接口名称 | 功能说明 |
| ------------ | ------------------------------------------------------------------------------------------- |
| 指示灯 | 单个 RGB 状态指示灯，用于指示网关运行状态。 |
| 按键 | 外凸功能按键，用于设备入网、子设备添加、消除报警、重置等。 |
| Type-C | 供电接口（5V⎓2A），亦可实现网络数据通信；可通过 Type-C 拓展坞外挂 4G 模块上网。 |
| RJ45 | 以太网接口（100Mbps），支持 IEEE 802.3af PoE 供电。 |
| 扬声器 | 1 个 2W 喇叭，支持自定义铃声与联动语音播报。 |

### 按键说明

| 操作方式 | 功能说明 |
|----------------------|--------------------------------------------------|
| 长按功能键 10 秒以上 | 恢复网络参数（用户配置数据不改变）；防误删开启时无法从设备端解绑。 |
| 快按功能键 10 次 | 恢复出厂设置。 |
| 按功能键 1 次 | 清除报警 / 停止添加子设备 / 终止语音播报。 |
| 快按功能键 2 次 | 撤防相关操作（取消报警并关闭当前守护模式等，详见产品说明）。 |
| 快按功能键 3 次 | 进入添加 Zigbee 子设备状态。 |
| 快按功能键 5 次+长按 3～5 秒 | 进入网络待机模式（关闭 Wi-Fi/Zigbee/Thread/BLE，有线网络仍可用）。 |

### 指示灯说明

| 指示灯状态 | 功能说明 |
| ------------ | ------------------------------------------------------------------------------------------- |
| 黄灯长亮 | 正在启动。 |
| 黄灯快闪 | 等待连接网络。 |
| 蓝灯快闪 | 连接网络中。 |
| 蓝灯慢闪 | 网络连接成功，账户绑定中 / 入网后离线。 |
| 蓝灯常亮 | 正常工作（账户绑定成功）。 |
| 白灯常亮 | 约10分钟内无法连接路由器 / 账户绑定失败，重新进入待入网配置。 |
| 紫灯慢闪 | 允许添加Zigbee子设备。 |
| 黄灯慢闪 | 固件升级中。 |
| 紫灯常亮 | 网络待机模式。 |
| 红灯快闪 3 次 | 防误删开启，无法从设备端删除。 |

### 主要能力

- 支持本地配网到 M300 的 Aqara Studio，可脱离云端 AIOT 使用。
- 可作为 Zigbee 网关和 Thread Border Router，连接 Aqara Zigbee 和 Thread 子设备。
- 支持 Matter Controller、Matter Bridge、Matter commissioner。
- 支持 2.4G & 5GHz 双频 Wi-Fi 6，以及 RJ45 有线联网。
- 支持 Type-C / PoE 双重供电。

## 排障指引

### 故障现象及可能的原因与解决方案

常见入网失败：
- 请通电后长按网关按键10秒以上，待黄灯闪烁后，重试添加；
- 检查路由器是否开启Wi-Fi防蹭设置，导致网关无法正常联网；
- 检查路由器是否开启AP隔离，导致手机在局域网内无法搜索到网关；
- 建议不要连接桥接网络。
