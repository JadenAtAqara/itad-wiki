## 产品概述

Aqara Edge Hub M300 是 Aqara Studio 空间智能操作系统的官方硬件控制器，兼具本地边界枢纽和网关功能。由于 Aqara Studio 平台已预装并直接嵌入 M300 的固态存储中（即“枢纽一体化”机型），该设备同时承担多项关键架构角色：

1. 高可用本地硬件控制器及主配网物理枢纽；
2. 多协议工业级网关，桥接无线拓扑与传统楼宇自动化有线标准；
3. 本地主机服务器，运行 Aqara Studio 基于 Web 的配置控制台和用户仪表盘界面；
4. 高性能本地执行引擎，承担复杂多线程脚本及边缘自动化任务；
5. 安全的本地 API 集成端点，并内置 MCP 服务器。

## 安装说明

### 安装条件确认

请选配最小输出参数为 5VDC 2A 的适配器搭配产品使用（产品出货不配适配器）；或使用支持 IEEE 802.3af 的 PoE 路由器/交换机通过 RJ45 供电。

本产品支持平放、壁挂与吸顶安装。摆台时请置于平整台面，勿遮挡正面红外发射区。

## 使用说明

### 快速设置

#### 1.选择供电方式

本产品支持使用 [Type-C](#type-c-供电) 或 [PoE](#poe-供电) 两种供电方式。

##### Type-C 供电

使用 5V⎓2A 电源适配器与 USB-A 转 USB-C 电源线连接网关 Type-C 接口供电（适配器需自备）。

##### PoE 供电

使用支持 PoE 的路由器或网络交换机，连接网关 RJ45 网口实现供电和网络连接。

:::tip
当既插入电源又使用 PoE 供电时，设备将优先从 PoE 口取电。
:::

#### 2.等待网关启动

指示灯黄灯长亮；完成启动后进入黄灯快闪（等待 Studio 登录/配置）。

#### 3.联网并访问 Aqara Studio

推荐有线连接：将 M300 通过网线接入路由器/交换机，电脑处于同一局域网，在浏览器输入机身管理地址贴纸上的地址（如 `aqarastudio-EEFF.local`）访问 Studio。

<img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/M300-pic2.png" alt="连接 Aqara Studio" style={{ width: '60%' }} />

首次使用需在 Studio Web 端初始化管理员账号密码；超时未初始化需重启设备后重试（非重置）。

## 产品功能

### 接口说明

| 接口名称 | 功能说明 |
| -- | -- |
| 指示灯 | 单个 RGB 状态指示灯 |
| 按键 | 外凸功能按键，用于入网、添加子设备、消除报警、重置等 |
| Type-C | 供电（5V⎓2A）及数据通信；可通过拓展坞外挂 4G/5G 模块上网 |
| RJ45 | 100Mbps 以太网，支持 IEEE 802.3af PoE |
| microSD | 扩展存储卡槽（最高 512GB） |
| 扬声器 | 支持铃声与语音播报 |
| 红外 | 6 路红外发射 + 1 路红外接收，支持红外学习与遥控 |

### 按键说明

| 操作方式 | 功能说明 |
| -- | -- |
| 长按功能键 10 秒 | 恢复网络参数（防误删设置关闭时可用；防误删设置打开时无响应，红灯快闪 3 次） |
| 快按功能键 10 次 | 恢复出厂设置（关闭[禁用按键恢复出厂设置](./../../factory-reset.mdx#禁用按键恢复出厂)时可用；打开禁用按键恢复出厂设置时无响应，红灯快闪 3 次） |
| 按功能键 1 次 | 停止添加子设备 / 终止语音播报 |
| 快按功能键 3 次 | 进入添加 Zigbee 子设备状态（紫灯慢闪） |
| 快按功能键 5 次+长按 3 秒 | 进入网络待机模式（关闭 Zigbee/Thread 等无线；紫灯常亮；重新上电后恢复） |

### 指示灯说明

| 指示灯状态 | 功能说明 |
| -- | -- |
| 黄灯长亮 | 正在启动 |
| 黄灯快闪 | 等待 Studio 登录/配置（请连接路由器并在浏览器输入管理地址） |
| 蓝灯快闪 | 连接网络中 |
| 蓝灯慢闪 | 入网后设备离线 |
| 蓝灯常亮 | Studio 登录完成，正常工作 |
| 白灯常亮 | 约 10 分钟内无法连接路由器 / 需重试配网 |
| 黄灯慢闪 | 网关固件或 Studio 固件升级中 |
| 紫灯慢闪 | 允许添加 Zigbee 子设备 |
| 紫灯常亮 | 网络待机模式 |
| 绿灯慢闪两次 | 添加子设备时点击“识别”网关 |
| 红灯快闪 3 次 | 防误删开启，相关删除/重置操作被禁止 |

### 主要能力

- 自身搭载 Aqara Studio，支持本地逻辑功能块、图形化自动化与 Web 管理
- 可作为 Zigbee 网关、Thread Border Router、Matter Controller / Matter commissioner
- 支持将 Zigbee 设备 Matter Bridge 至第三方平台
- 支持 2.4G & 5GHz 双频 Wi-Fi 5 与 RJ45 有线联网，支持静态 IP
- 支持 Type-C / PoE 双重供电
- 支持红外遥控与学习、铃声播放、本地日志存储、SD 卡扩展
- 支持子设备防误删、设置静态 IP、整机重启等 B 端运维能力

## 排障指引

### 故障现象及可能的原因与解决方案

常见配置失败：

- 通电后长按功能键 10 秒以上，待黄灯快闪后重试；
- 确认设备与电脑处于同一局域网，并正确输入机身管理地址；
- 检查路由器是否开启 Wi-Fi 防蹭网、AP 隔离；
- 建议不要连接桥接网络；
- 首次初始化账号超时后，请重启设备（非重置）再进入初始化流程。

防误删导致无法重置/恢复出厂：请在 Aqara Studio 中调整[防误删设置和禁用按键恢复出厂设置](./../../factory-reset.mdx)后再操作。
