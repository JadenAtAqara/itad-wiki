## 产品概述

四路控制模块 AW110K 是一款低压直流输入的智能控制模块，支持 DIN 导轨安装。单路最大支持 16A 负载，并采用高精度电流互感器实现每路独立电流检测。该模块配备四个独立回路控制按键，通过 RS485 接口，连接 Aqara 配电箱网关使用，支持稳定、远距离的开关控制。产品具备过温和过载保护功能，确保运行安全。配合兼容的自动化系统，模块可实现远程控制、定时调度、实时能耗监测与电量统计，并可与其他智能设备联动，构建多种自动化场景.

## 安装说明

### 安装条件确认

安装工具：连接线（建议使用双绞线或AWG 28电子线，需自行准备）

### 安装注意事项

- 接线前，请务必断开总电源，确保设备处于完全断电状态，避免发生触电、短路等电气事故。接线前，请将配件袋内的接线端子插入设备底部接口，用于后续设备接线。
- 建议使用符合电气安装规范的线材进行连接，并根据端子规格预留约 8mm 的剥线长度。接线外径推荐为 1.05mm。 接线完成后，请确认所有导线已可靠插入端子，并锁紧固定。

### 安装步骤

#### 步骤一：安装模块

断开总电源后，将四路控制模块安装在 DIN 导轨上。为便于描述，以下将“四路控制模块”简称为“模块”。

<img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/din-rail-module-4-channels-aw110k-pic2.png" alt="安装模块"  style={{ width: '60%' }} />

#### 步骤二：连接网关与首个模块

将 Aqara 配电箱网关接线端子的 A、B、GND 分别连接至首个模块对应的 A、B、GND 接线端子。除了第一个模块的 GND 链接自身的 ADD\_I,，其他模块的 GND 口可以不做连接。

<img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/din-rail-module-4-channels-aw110k-pic3.png" alt="连接网关与首个模块"  style={{ width: '60%' }} />

#### 步骤三：连接模块之间的通讯线

多个模块之间采用“手拉手”方式串联连接，最多支持连接 32 个模块。

- ADD\_I / ADD\_O 接法 将首个模块的 ADD\_O 接口连接至第二个模块的 ADD\_I 接口，首个模块的 ADD\_I 接口连接至 GND 口； 再将第二个模块的 ADD\_O 接口连接至第三个模块的 ADD\_I 接口； 以此类推，依次串联。 最末尾模块的 ADD\_O 接口无需连接，保持悬空。 ADD\_I 和 ADD\_O 为模块通讯信号的输入与输出端口，用于识别模块之间的连接顺序。
- A / B 接法 各模块的 A、B 接线端子按照顺序依次手拉手连接，保持 A 对 A、B 对 B，不可交叉连接。

<img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/din-rail-module-4-channels-aw110k-pic4.png" alt="连接模块之间的通讯线" />

#### 步骤四：连接负载

将四路负载线，例如灯具、插座或其他受控设备，依次接入模块对应的负载端子。 接线完成后，请确认所有负载线连接牢固，无松动、裸露或误接情况。

<img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/din-rail-module-4-channels-aw110k-pic5.png" alt="连接负载"  style={{ width: '40%' }} />

#### 步骤五：上电检查

确认所有接线正确无误后，打开总电源。 检查模块供电是否正常，指示灯是否进入正常工作状态。如发现异常，请立即断电，并检查接线。设备须外接额定电流为16A的电流保护装置。

### 电源接线

将电源的 V-、V+ 分别连接至网关和模块对应的 V-、V+ 接线端子。 

网关与各模块之间的 V-、V+ 需按照顺序依次手拉手连接，保持 V- 对 V-、V+ 对 V+，不可交叉连接。

<img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/din-rail-module-4-channels-aw110k-pic6.png" alt="电源接线" />

确认模块通讯线、电源线及负载线均连接正确后，连接并打开主电源，使设备进入正常工作状态。 

如模块指示灯异常、负载无法控制或设备无法识别，请立即断电，并检查 A、B、GND、ADD\_I、ADD\_O、V-、V+ 及负载端子的接线是否正确。

<img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/din-rail-module-4-channels-aw110k-pic7.png" alt="接线检查"  style={{ width: '60%' }} />

## 产品功能

### 产品功能说明

#### 四路开关控制 

四路控制模块最多可独立控制 4 路回路，适用于灯具、插座或其他用电设备的分路控制。 用户可根据实际需求，分别对各通道进行本地开关控制或远程开关控制。 远程控制需配合 Aqara 配电箱网关使用，并接入 Aqara Studio 后进行配置和操作。

#### 互斥开关 

互斥开关功能可避免指定通道之间同时开启，从而防止冲突操作，提高设备运行的安全性和可靠性。 

该功能适用于需要互锁控制的设备或回路，例如窗帘电机、正反转电机或其他不可同时通电的控制场景。 

用户可根据实际需求，在 Aqara Studio 中配置需要互斥的通道。 

该功能需配合 Aqara 配电箱网关使用，并接入 Aqara Studio 后进行配置。点击开关互锁使能配置，将需要配置互锁的两个电路配置相同的写入值（如：6、66、88 等）。

#### 上电开关（断电记忆）设置 

上电开关（断电记忆）功能可设置设备在断电后重新上电时的开关状态，减少手动恢复操作，确保设备按预期状态运行。 

可设置的上电状态包括： 

| 上电状态   | 说明                       |
|----------|--------------------------|
| 上电记忆   | 恢复至断电前的开关状态          |
| 上电通电   | 重新上电后通道自动开启          |
| 上电断电   | 重新上电后通道保持关闭          |

设备默认设置为“上电记忆”。 

该功能需配合 Aqara 配电箱网关使用，并接入 Aqara Studio 后进行配置。

#### 电流与功率测量 

设备支持实时监测各通道的电路电流、功率数据，帮助用户了解用电情况。 

用户可通过 Aqara Studio 查看相关数据，用于辅助判断设备运行是否正常，并优化用电管理。 

:::note
功率计量需要用户在电压值页面配置对应的电压后方可进行功率的估算。 

该功能需配合 Aqara 配电箱网关使用，并接入 Aqara Studio 后查看。
:::

#### 过温与过载保护 

设备支持过温保护和过载保护功能。当检测到温度或电流异常时，设备将自动执行保护动作，降低设备损坏或电气安全风险。 

部分保护策略需要通过 Aqara Studio 进行配置。保护策略配置及报警推送需配合 Aqara 配电箱网关使用，并接入 Aqara Studio 后实现。

##### 过载保护 

设备通过电流检测判断负载状态。当任一路通道检测到电流超过设定负载范围时，设备将自动断开对应继电器，并进入安全保护状态，同时向用户推送危险报警。 

过载保护策略支持以下设置： 
- 单路过载 → 单路断电； 
- 单路过载 → 全路断电。 

如用户未进行设置，默认执行“单路过载 → 单路断电”。 

##### 过温保护 

设备通过内部温度检测判断运行状态。当设备内部检测温度超过 65 ℃ / 149 ℉ 时，设备将自动断开继电器，并进入安全保护状态，同时向用户推送危险报警。 

过温保护触发后，设备四路继电器均会强制断电，以保障设备和电气安全。 

##### 安全保护状态说明 

安全保护状态下，设备将限制对应通道或全部通道的输出，避免异常状态持续扩大。当设备恢复正常后，用户可按下任一电源按键，解除设备安全保护状态。

## 注意事项

- 本产品为低压输入控制设备，设计用于安装在配电箱内，必须由具备资质的电工或具有相关经验的专业人员进行安装、 接线和调试。
- 在安装、接线或维护前，务必关闭配电箱的主电源开关，并确认已完全断电，以避免触电或短路风险。
- 本产品仅适用于室内干燥环境，配电箱应具备良好的防潮、防尘性能。
- 确保所有接线连接牢固，导线符合电气标准，防止因接线松动或导线过载导致的过热或损坏。
- 避免配电箱内部温度过高，确保配电箱符合相关安装标准。
- 禁止水、油或其他液体进入配电箱或本产品内部，以防止设备损坏或故障。
- 禁止自行拆卸、改装或绕过本产品的安全保护功能，所有维修必须由授权专业人员执行。
- 本产品适用于智能家居集中控制与能耗管理，因不当安装或误用造成的风险、系统故障或财产损失，制造商概不负责。
- **设备须外接电流保护装置，额定电流 16A。**

## 常见问题

### 四路控制模块AW110K是否支持第三方RS485协议，例如Modbus RTU、BACnet MS/TP等？

目前不支持。

### 有线协议RS-485相比无线协议Zigbee&Thread的优缺点？

RS-485 简单可靠，一旦部署几乎无需维护，但需要前装部署，新增设备较困难。
