# 自定义设备创建

本文描述如何通过 Studio 本地 API 创建一个自定义设备，并整合 Aqara Studio 内不同设备的多个功能点，实现更高效的设备统一管理与控制。

## 1 创建自定义设备

通过 Studio 本地 API [`POST` /open/api/v1/virtual-devices](./../../data-export-api/add-virtual-device.api.mdx) 接口，创建一个自定义设备，获取该自定义设备 ID。

请求示例：
```json
{
  "name": "Custom Virtual Device",
  "virtualDeviceType": "virtual"
}
```

响应示例：
```json
{
  "type": "VirtualDeviceAddResponse",
  "version": "v1",
  "msgId": "1",
  "data": {
    "deviceId": "virtual.1790253917450"
  },
  "code": 0,
  "message": "success"
}
```

## 2 查询设备信息列表

通过 Studio 本地 API [`GET` /open/api/v1/devices](./../../data-export-api/get-devices.api.mdx) 接口可获取 Aqara Studio 当前已接入的所有设备信息。在返回的设备列表中，您可以根据实际需求挑选一个或多个设备的 `deviceId`，作为功能点来源，后续将在自定义设备中整合这些设备的功能点。

## 4 绑定功能点到自定义设备

通过 Studio 本地 API [`POST` /open/api/v1/virtual-devices/points/bind](./../../data-export-api/bind-virtual-device-points.api.mdx) 接口，将上述选中的功能点绑定到您创建的自定义设备。

以下请求示例展示了如何将 Smart Switch T1 的 2 个特征（trait）和 1 个命令（Command），以及 Climate Sensor W100 的 1 个特征，绑定到自定义设备上。

```json
{
  "deviceId": "virtual.1790253917450",
  "sourcePoints": [
    {
      "deviceId": "lumi.54ef4410000d9618",
      "endpointId": 2,
      "functionCode": "Output",
      "traitCode": "OnOff"
    },
    {
      "deviceId": "lumi.54ef4410000d9618",
      "endpointId": 2,
      "functionCode": "Output",
      "traitCode": "StartUpOnOff"
    },
    {
      "deviceId": "lumi.54ef4410000d9618",
      "endpointId": 2,
      "functionCode": "Output",
      "commandCode": "Toggle"
    },
    {
      "deviceId": "matt.04692c7f67c43e582d",
      "endpointId": 2,
      "functionCode": "Temperature",
      "traitCode": "CurrentTemperature"
    }
  ]
}
```

响应示例如下：
```json
{
  "type": "VirtualDeviceBindPointsResponse",
  "version": "v1",
  "msgId": "4",
  "data": "",
  "code": 0,
  "message": "success"
}
```

## 5 从自定义设备解绑功能点

如果您不需要某些功能点，可通过通过 Studio 本地 API [`POST /open/api/v1/virtual-devices/points/unbind`](./../../data-export-api/unbind-virtual-device-points.api.mdx) 接口，将这些功能点从自定义设备中解绑。

以下请求示例展示了如何将 Smart Switch T1 的 `StartUpOnOff` 功能点从自定义设备上解绑：

```json
{
  "deviceId": "virtual.1790253917450",
  "sourcePoints": [
    {
      "deviceId": "lumi.54ef4410000d9618",
      "endpointId": 2,
      "functionCode": "Output",
      "traitCode": "StartUpOnOff"
    }
  ]
}
```

响应示例如下：
```json
{
  "type": "VirtualDeviceUnbindPointsResponse",
  "version": "v1",
  "msgId": "5",
  "data": "",
  "code": 0,
  "message": "success"
}
```
