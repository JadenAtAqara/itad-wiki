# Custom Device Creation

This article describes how to create a custom device via Studio's local API and integrate multiple function points from various Aqara Studio devices to achieve more efficient unified device management and control.

## 1. Create a Custom Device

Use the Studio local API [`POST` /open/api/v1/virtual-devices](./../../data-export-api/add-virtual-device.api.mdx) endpoint to create a custom device, and obtain the custom device ID.

Sample Request:
```json
{
  "name": "Custom Virtual Device",
  "virtualDeviceType": "virtual"
}
```

Sample Response:
```json
{
  "type": "VirtualDeviceAddResponse",
  "version": "v1",
  "msgId": "1",
  "data": {
    "deviceId": "virtual.1790253917450"
  },
  "code": 0,
  "message": "success"
}
```

## 4. Bind Function Points to the Custom Device

Use the Studio local API [`POST` /open/api/v1/virtual-devices/points/bind](./../../data-export-api/bind-virtual-device-points.api.mdx) endpoint to bind the selected function points above to the custom device you created.

The following sample request demonstrates how to bind two traits and one command from the Smart Switch T1, as well as one trait from the Climate Sensor W100, to the custom device.

```json
{
  "deviceId": "virtual.1790253917450",
  "sourcePoints": [
    {
      "deviceId": "lumi.54ef4410000d9618",
      "endpointId": 2,
      "functionCode": "Output",
      "traitCode": "OnOff"
    },
    {
      "deviceId": "lumi.54ef4410000d9618",
      "endpointId": 2,
      "functionCode": "Output",
      "traitCode": "StartUpOnOff"
    },
    {
      "deviceId": "lumi.54ef4410000d9618",
      "endpointId": 2,
      "functionCode": "Output",
      "commandCode": "Toggle"
    },
    {
      "deviceId": "matt.04692c7f67c43e582d",
      "endpointId": 2,
      "functionCode": "Temperature",
      "traitCode": "CurrentTemperature"
    }
  ]
}
```

Sample Response:
```json
{
  "type": "VirtualDeviceBindPointsResponse",
  "version": "v1",
  "msgId": "4",
  "data": "",
  "code": 0,
  "message": "success"
}
```

## 5. Unbind Function Points from the Custom Device

If you no longer need some function points, you can use the Studio local API [`POST /open/api/v1/virtual-devices/points/unbind`](./../../data-export-api/unbind-virtual-device-points.api.mdx) endpoint to unbind these points from the custom device.

The following sample request demonstrates how to unbind the `StartUpOnOff` function point from Smart Switch T1 on the custom device:

```json
{
  "deviceId": "virtual.1790253917450",
  "sourcePoints": [
    {
      "deviceId": "lumi.54ef4410000d9618",
      "endpointId": 2,
      "functionCode": "Output",
      "traitCode": "StartUpOnOff"
    }
  ]
}
```

Sample Response:
```json
{
  "type": "VirtualDeviceUnbindPointsResponse",
  "version": "v1",
  "msgId": "5",
  "data": "",
  "code": 0,
  "message": "success"
}
```
