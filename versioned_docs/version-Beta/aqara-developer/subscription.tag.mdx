# Subscription

Use MQTT subscriptions to receive device data and supported events from Studio. The following pages describe connection setup, authentication, subscription requests and delivery rules:

- [Data Export by MQTT](../aqara-studio/data-export-by-mqtt.mdx): enable MQTT export and choose the local or a third-party Broker.
- [MQTT API](./data-export-api/mqtt-api/mqtt-api.mdx): request and response topics, subscription filters, heartbeat and lease renewal, notifications and error responses.
