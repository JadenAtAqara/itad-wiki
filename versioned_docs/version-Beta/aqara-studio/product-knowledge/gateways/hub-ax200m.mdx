## Product Overview

Aqara Hub AX200M is the B-end version of Hub M200 (Nand Flash upgraded from 128 MB to 256 MB). It is designed for enterprise users and system integrators, and can serve as an extension hub with Hub M300 to expand coverage. It supports Aqara Zigbee and Thread devices, dual-band 2.4/5 GHz Wi-Fi 6, dual power supply via Type-C and PoE, local pairing to Aqara Studio on M300 for use without cloud AIoT, Matter Controller / Thread Border Router, Matter Bridging of Zigbee child devices to third-party Matter ecosystems, custom ringtones and personalized automation voice announcements, and B-end dedicated child devices.

## User Instructions

### Quick Setup

#### 1. Select Power Supply Method

This product supports two power supply methods: [Type-C](#type-c-power) and [PoE](#poe-power).

##### Type-C Power

Use a 5V⎓2A power adapter with a USB Type-C cable to power the hub via the Type-C port.

##### PoE Power

Use a PoE device that supports IEEE 802.3af to power the hub via an RJ45 Ethernet cable (48V⎓0.25A).

#### 2. Wait for the Hub to Start

The indicator stays solid yellow during startup, then switches to fast flashing yellow (waiting for connection).

#### 3. Hub Binding

Wired pairing: Connect Hub AX200M to a router/switch via Ethernet, place it on the same LAN as M300, then sign in to the Aqara Studio management page to complete pairing (read the [Aqara Hub Integration Guide](./../../device-integration/aqara.mdx) for details).

### Button Description

| Operation | Description |
|----------------------|--------------------------------------------------|
| Press and hold the function button for more than 10 seconds | reset network parameters (user configuration data remains unchanged); when anti-misdelete is enabled, unbinding from the device side is not available |
| Press the function button quickly 10 times | restore factory settings |
| Press the function button once | clear alarm / stop adding child devices / stop voice announcement |
| Press the function button quickly 2 times | disarm-related actions (cancel alarm and turn off the current guard mode, etc.; see product instructions for details) |
| Press the function button quickly 3 times | enter Zigbee child device pairing mode |
| Press the function button quickly 5 times, then press and hold for 3-5 seconds | enter network standby mode (Wi-Fi/Zigbee/Thread/BLE off; wired network remains available) |

### Indicator Description

| Indicator status | Description |
| ------------ | ------------------------------------------------------------------------------------------- |
| Solid yellow | starting up |
| Fast flashing yellow | waiting for network connection |
| Fast flashing blue | connecting to network |
| Slow flashing blue | network connected, account binding in progress / offline after pairing |
| Solid blue | working normally (account bound successfully) |
| Solid white | unable to connect to the router within about 10 minutes / account binding failed; re-enter waiting-for-pairing configuration |
| Slow flashing purple | Zigbee child device pairing allowed |
| Slow flashing yellow | firmware upgrading |
| Solid purple | network standby mode |
| Fast flashing red 3 times | anti-misdelete enabled; cannot delete from the device side |

## Troubleshooting Guide

### Fault Symptoms, Possible Causes, and Solutions

Common pairing failures:
- After power-on, press and hold the hub button for more than 10 seconds, wait until the yellow light flashes, then retry adding;
- Check whether the router has Wi-Fi anti-sharing settings enabled, which may prevent the hub from connecting to the network;
- Check whether the router has AP isolation enabled, which may prevent the phone from discovering the hub on the LAN;
- Avoid connecting to bridged networks.
