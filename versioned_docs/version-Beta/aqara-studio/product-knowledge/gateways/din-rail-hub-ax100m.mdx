## Product Overview

### Product Overview

Aqara DIN Rail Hub AX100M is a hub designed to meet DIN rail installation requirements for distribution boxes, and can be mounted on a standard DIN rail. It supports both Zigbee and Thread protocols, Matter Controller and Thread Border Router functions, and can act as a Matter Bridge to connect bound Zigbee child devices to third-party Matter ecosystems. It supports Aqara RS-485 child devices, enabling pairing, network configuration, and control management via wired RS485 connection. It supports dual-band 2.4 GHz and 5 GHz Wi-Fi, and can be powered via USB Type-C or a power module.

## Installation Instructions

### Installation Prerequisites

Installation tools: connecting wires (twisted pair or AWG 28 electronic wire recommended; to be prepared by the user)

### Installation Precautions

Before installation, make sure the main power switch is turned off! Wire the hub only when it is powered off to avoid electrical accidents.
Use with the dedicated Aqara power module. The power module outputs 24 V and can supply power to the DC ports of Aqara DIN Rail Hub AX100M and Aqara RS-485 child devices. If another power module is required, confirm the specifications with Aqara technical support before installation to avoid damage.

## User Instructions

### Quick Setup

**1. Select power supply method and install**
\*Before installation, make sure the main power switch is turned off! Wire the hub only when it is powered off.
**1.1. Power via power module DC port**
1. Turn off the main power supply switch;
2. Insert the matching female terminal into the hub DC interface;
3. Connect the hub V+ and V- ports to the power module output V+ and V- with connecting wires;
4. Connect the mains wires to the power module input, then turn on the main power supply.
**1.2. Power via Type-C**
Use a 5V⎓1A power adapter with a USB Type-C cable to connect the adapter to the hub Type-C port for power supply (power cable and adapter are not included).
**2. Hub antenna installation**
Due to the installation environment, the distribution box may shield Zigbee and Thread signals. Use the antenna included in the package. Screw the antenna SMA connector into the SMA port on the hub, and install the antenna outside the distribution box so the hub can communicate with Zigbee and Thread child devices outside the box.
**3. Wait for the hub to start**
The hub indicator changes from solid yellow to fast flashing yellow.
**4. Hub binding**
Connect DIN Rail Hub AX100M to the router, place it on the same LAN as M300, then sign in to the M300 Studio management page. See the Aqara Hub pairing guide for details.
![image](https://alidocs.oss-cn-zhangjiakou.aliyuncs.com/res/5VLqXL5JEYm1ZqX1/img/c924f5e7-9f16-4194-a8d6-2a28436defc5.png)
**5. Bind child devices**
Bind Zigbee devices: see the Zigbee device pairing guide
Bind Aqara RS-485 devices: see the Aqara RS-485 device pairing guide
Bind Matter Over Thread devices: Thread devices must be bound to AX100M via the Aqara Life app
**6. Reset network parameters**
Press and hold the function button for more than 10 seconds: reset network parameters (user configuration data remains unchanged). When anti-misdelete mode is enabled, unbinding from the hub side is not available.
**7. Factory reset**
Press the function button quickly 10 times: restore factory settings (clear all user data to factory state).

Press and hold the function button for more than 10 seconds: reset network parameters (user configuration data remains unchanged); when anti-misdelete mode is enabled, unbinding from the hub side is not available
Press the function button quickly 10 times: restore factory settings (clear all user data to factory state)
Press the function button quickly 3 times: enter Zigbee child device pairing mode
**Indicator description**
Solid yellow: starting up
Fast flashing yellow: waiting for network connection
Fast flashing blue: connecting to network
Slow flashing blue: network connected, account binding in progress
Solid blue: working normally
Solid white: powered on for 10 minutes without network configuration
Flashing purple: child device pairing allowed
Slow flashing yellow: firmware upgrading
Off: indicator turned off / hub not powered / hub in sleep mode

1. Can serve as a Zigbee hub and Thread Border Router to connect Aqara Zigbee and Thread child devices
2. Can serve as a Matter Bridge to connect bound Aqara Zigbee child devices to third-party Matter ecosystems
3. Supports Matter Controller to add third-party Matter devices
4. Connects Aqara RS-485 child devices via RS485 wired interface (supports up to 32 Aqara RS-485 child devices) for pairing, connection, and control
5. Supports dual-band 2.4 GHz & 5 GHz Wi-Fi 6 wireless networking and RJ45 wired networking

## FAQ

### DIN Rail Hub AX100M FAQ

Q: Does DIN Rail Hub AX100M support third-party RS485 protocols such as Modbus RTU or BACnet MS/TP?
A: It is supported at the hardware level and theoretically supportable in software, but this has not been developed yet and needs to be evaluated based on actual customer requirements.
Q: What are the pros and cons of wired RS-485 compared with wireless Zigbee & Thread?
A: RS-485 is simple and reliable, and once deployed requires almost no maintenance; however, it requires pre-installation and makes adding new devices more difficult.
