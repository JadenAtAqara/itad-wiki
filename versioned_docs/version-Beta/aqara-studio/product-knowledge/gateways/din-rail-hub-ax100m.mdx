## Product Overview

Aqara DIN Rail Hub AX100M is a hub designed to meet DIN rail installation requirements for distribution boxes, and can be mounted on a standard DIN rail. It supports both Zigbee and Thread protocols, Matter Controller and Thread Border Router functions, and can act as a Matter Bridge to connect bound Zigbee sub-devices to third-party Matter ecosystems. It supports Aqara RS-485 sub-devices, enabling pairing, network configuration, and control management via wired RS485 connection. It supports dual-band 2.4 GHz and 5 GHz Wi-Fi, and can be powered via USB Type-C or a power module.

## Installation Instructions

### Installation Prerequisites

Installation tools: connecting wires (twisted pair or AWG 28 electronic wire recommended; to be prepared by the user)

### Installation Precautions

- Before installation, make sure the main power switch is turned off! Wire the hub only when it is powered off to avoid electrical accidents.
- Use with the dedicated Aqara power module. The power module outputs 24 V and can supply power to the DC ports of Aqara DIN Rail Hub AX100M and Aqara RS-485 sub-devices. If another power module is required, confirm the specifications with Aqara technical support before installation to avoid damage.

## User Instructions

### Quick Setup

#### 1. Select Power Supply Method and Install

This product supports two power supply methods: using a [power module](#power-via-power-module-dc-port) or [Type-C](#power-via-type-c).

:::warning
Before installation, make sure the main power switch is turned off! Wire the hub only when it is powered off.
:::

##### Power via Power Module DC Port

1. Turn off the main power supply switch;
2. Insert the matching female terminal into the hub DC interface;
3. Connect the hub V+ and V- ports to the power module output V+ and V- with connecting wires;
4. Connect the mains wires to the power module input, then turn on the main power supply.

##### Power via Type-C

Use a 5V⎓1A power adapter with a USB Type-C cable to connect the adapter to the hub Type-C port for power supply (power cable and adapter are not included).

#### 2. Hub Antenna Installation

Due to the installation environment, the distribution box may shield Zigbee and Thread signals. Use the antenna included in the package. Screw the antenna SMA connector into the SMA port on the hub, and install the antenna outside the distribution box so the hub can communicate with Zigbee and Thread sub-devices outside the box.

#### 3. Wait for the Hub to Start

The hub indicator changes from solid yellow to fast flashing yellow.

#### 4. Hub Binding

Connect DIN Rail Hub AX100M to the router, place it on the same LAN as M300, then sign in to the M300 Aqara Studio management page. See the [Aqara Hub Integration Guide](./../../device-integration/aqara.mdx) for details.

### Button Description

| Operation | Description |
|----------------------|--------------------------------------------------|
| Press and hold the function button for more than 10 seconds | Reset network parameters (user configuration data remains unchanged); when anti-misdelete mode is enabled, unbinding from the hub side is not available |
| Press the function button quickly 10 times | Restore factory settings (clear all user data to factory state) |
| Press the function button quickly 3 times | Enter Zigbee sub-device pairing mode |

## Troubleshooting Guide

### Fault Symptoms, Possible Causes, and Solutions

Common pairing failures:
- After power-on, press and hold the hub button for more than 10 seconds, wait until the yellow light flashes, then retry adding;
- Check whether the router has Wi-Fi anti-sharing settings enabled, which may prevent the hub from connecting to the network;
- Check whether the router has AP isolation enabled, which may prevent the phone from discovering the hub on the LAN;
- Avoid connecting to bridged networks.

## FAQ

### DIN Rail Hub AX100M FAQ

#### Does DIN Rail Hub AX100M support third-party RS485 protocols such as Modbus RTU or BACnet MS/TP?

Not supported.

#### What are the pros and cons of wired RS-485 compared with wireless Zigbee & Thread?

RS-485 is simple and reliable, and once deployed requires almost no maintenance; however, it requires pre-installation and makes adding new devices more difficult.
