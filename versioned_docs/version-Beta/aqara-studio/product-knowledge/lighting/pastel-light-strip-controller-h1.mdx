## Product Overview

The Pastel Light Strip Controller H1 adopting new-generation quad-color mixing technology. It supports wider color temperature range (1800K-12000K) and rich tinted color light expression, meeting lighting needs for different scenarios.

Compared to traditional dual color temperature solutions, this technology provides more delicate light color changes, making the light environment closer to natural light variation patterns, thereby enhancing comfort and layering of space illumination. The controller adopts DC 12-24V input with output power up to 480W Max, capable of driving longer LED strips. Output ports include LED+ x2, R, G, B, W totaling 5 channels, supporting only single output, not multi-channel independent control.

The device supports Zigbee and Thread dual protocol connection (factory default is Zigbee), and can access Aqara Studio or Matter-compatible third-party ecosystems according to usage environment. It supports static and dynamic scene customization, 0~10s gradient transition, custom lighting transition curves and other advanced configurations. Combined with other Aqara smart devices, rich automation functions can be achieved.

- This device requires use with Aqara gateway for full functionality support. Certain specific features are only supported within the Aqara ecosystem.

## User Guide

### Quick Setup

#### Device Installation

:::caution
Installation involves high voltage; please ensure main power switch is closed and operation performed by professional electrician.
:::

1. Fix Controller: Use M3 x 8mm self-tapping screws to fix controller in suitable position.
2. Connect LED Strip: Connect LED strip's LED+, R, G, B, W wires to corresponding output ports on controller.
3. Connect Power: Connect DC 24V power supply output to controller's power input terminal (observe polarity).

<img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/pastel-light-strip-controller-h1-install.png" alt="Pastel Light Strip Controller H1 Installation" />

#### Power On Device

Turn on power and confirm device is powered normally (when factory-default not-joined state, light breathes twice).

#### Device Pairing

Device defaults to Zigbee protocol for network joining. After device enters pairing mode, it can be added to Aqara Studio or Aqara Life App for use.

:::note
When device is not joined to network, upon powering on, light breathes twice and automatically enters pairing mode. Pairing time is 60s. If pairing time is exceeded, device can be power-cycled to re-enter pairing mode.
:::

#### Device Reset / Factory Restore

| Operation | Operation Method | Description |
| --- | --- | --- |
| Device Reset | Long press reset button for 5s or more OR cycle power 5 times (keep powered on last time) | Light breathes twice, reset successful. Device only clears network pairing and re-enters pairing state. |
| Factory Restore | Press reset button 10 times OR cycle power 10 times (keep powered on last time) | Light breathes twice, factory restore successful. Device clears all configuration information and re-enters pairing state. |

## FAQ

### Can Pastel Light Strip Controller H1 only be used with Pastel LED Strip H1?

Yes. controller is specifically designed for use with Pastel LED Strip H1 does not support single color temperature, dual color temperature, or RGB LED strips. Different specifications of quad-color tinted LED strips may be launched in future based on actual production needs.

### Can Pastel Light Strip Controller H1 control multiple channels independently? For example, can dual color temperature LED strip modules control two channels independently?

No, only single channel.

### Can Pastel Light Strip Controller H1 be connected directly to mains?

No, controller input voltage is DC 12-24V, needs to be used with power supply outputting DC 24V.

### How to enter pairing mode?

When device is not joined to network, upon powering on, light breathes twice and automatically enters pairing mode. Pairing time is 60s. If pairing time is exceeded, device can be power-cycled to re-enter pairing mode.

### How to reset device?

Long press reset button on controller for 5s or more, or cycle power 5 times (keep device powered on last time). If light breathes twice, reset is successful. After device reset, device only clears network pairing and re-enters pairing state.

### How to factory restore?

Press reset button on driver 10 times or cycle power 10 times (keep device powered on last time). If light breathes twice, factory restore is successful. After factory restore, device clears all configuration information and re-enters pairing state.

### How to switch protocol?

If need to switch protocol during device usage, first remove device in Aqara Life App, then long press device reset button for 5 seconds to reset device, enter pairing process, click "Switch Protocol" on device pairing screen and select required protocol, complete setup according to application instructions. Note: Switching protocol is equivalent to factory restore, will clear all device settings and data.

### Does device support power-off memory function?

Yes, device factory default is "Restore state at power-off". User can change post-power-on state according to own needs in post-power-on state settings, can also set to lights on after power-on, lights off after power-on, and reverse (opposite to state before power-off).

### What other features does device have?

Pastel Light Strip Controller H1 series supports static and dynamic scene customization; also has on/off transition time setting function, supports 0~10s gradient duration range selection; supports custom lighting transition curves and other advanced configurations; additionally, combined with other Aqara smart devices, can achieve richer automation functions.

### What is the actual display of color temperature and color palette for light groups composed of different types of lights?

1 Dual color temperature lights and colored lights grouped together, only color temperature control within group, when color temperature ranges differ, take intersection; 2 Tinted lights and tinted lights grouped together, group has color temperature and tinted color palette; 3 Tinted lights and RGB lights grouped together, take RGB color values.
