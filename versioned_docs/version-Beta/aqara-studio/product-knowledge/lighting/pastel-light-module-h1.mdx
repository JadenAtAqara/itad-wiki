## Product Overview

Aqara Pastel Light Module H1 is a small-size quad-color (RGBW) LED blockchain light source module specifically designed for light film scenarios. It adopts 70 x 70mm small square aluminum substrate PCB design (with screw holes), offering more flexible assembly and superior heat dissipation. Product built-in 16 units of 2835 LEDs, supports red, green, blue, white four-color independent PWM dimming, capable of achieving full gamut color mixing and precise color temperature adjustment.

Suitable for stretch ceiling, advertising light box, home decoration, engineering projects, buildings, hotels, shopping malls, decorative lighting and other light film lighting scenarios.

- This device requires use with Aqara gateway and [Lighting Scene Controller AW100L](./lighting-scene-controller-aw100l.mdx) for full functionality support. Certain specific features are only supported within the Aqara ecosystem.

### Installation Precautions

- Please confirm power is turned off before installation to avoid electrical accidents;
- Perform wiring and installation operations in powered-off state;
- Recommended maximum blockchain cascade quantity is 12 boards; power reinjection required if exceeded;
- Pay attention to signal arrow direction during wiring; do not reverse, otherwise entire light will not work;
- When using maximum power, blockchain light source requires sufficient heat dissipation (light box must have aluminum heat dissipation back panel);
- Do not bend or excessively pull light board connection cables.
    
### Installation Steps

Light boards need to be used together with scene controller. Complete installation steps and functions see [Lighting Scene Controller AW100L](./lighting-scene-controller-aw100l.mdx).

## Maintenance

- Regularly wipe light board surface with dry soft cloth to avoid dust accumulation affecting light output;
- Do not use chemical solvents to clean light board;
- When not in use for extended periods, store in dry environment after disconnecting power.

## Troubleshooting Guide

### Issue 1: Light Board Not Lighting

| Possible Cause | Solution |
| -- | -- |
| <ul><li>Incorrect power wiring, polarity reversed</li><li>Driver power supply DC24V no output</li><li>Light board physical damage</li></ul> | <ol><li>Check if power wiring is correct, confirm polarity is correct;</li><li>Check if driver power supply DC24V is outputting normally;</li><li>Check if light board has physical damage.</li></ol> |

### Issue 2: Cascaded Light Boards Partially Not Lighting

| Possible Cause | Solution |
| -- | -- |
| <ul><li>Signal line arrow direction reversed</li><li>Cascade quantity exceeded 12 boards without power reinjection</li><li>Power reinjection circuit not correctly connected</li></ul> | <ol><li>Check if signal line arrow direction is correct; do not reverse;</li><li>Check if cascade quantity exceeds 12 boards (power reinjection required if exceeded 12 boards);</li><li>Check if power reinjection circuit is correctly connected.</li></ol> |

### Issue 3: Abnormal Dimming / Flickering

| Possible Cause | Solution |
| -- | -- |
| <ul><li>Driver power supply power mismatch</li><li>SPI signal line connection abnormal</li><li>Signal interference</li></ul> | <ol><li>Check if driver power supply power matches;</li><li>Confirm SPI signal line connection is normal;</li><li>Check if signal interference exists.</li></ol> |

### Issue 4: Cannot Join Network

| Possible Cause | Solution |
| -- | -- |
| <ul><li>Light board not powered or not within gateway signal range</li><li>Gateway device quantity reached limit</li></ul> | <ol><li>Ensure light board is powered and within gateway signal range;</li><li>Reset light board and re-pair;</li><li>Check if gateway has reached device quantity limit.</li></ol> |

## FAQ

### What is the difference between small board and large board?

Small board (70 x 70mm) has 16 LEDs, RGBW four colors fully on 920lm/board, 8W/board, maximum cascade 12 boards, with screw holes for flexible installation; Large board (496 x 246mm) has 128 LEDs, RGBW four colors fully on 4800lm/board, 48W/board, maximum cascade 4 boards. Both support quad-color mixing and intelligent control.

### Can multiple small boards be used in series?

Yes. Small boards support cascading, maximum cascade quantity is 12 boards. Power reinjection required if exceeded.

### What should I pay attention to when wiring small boards?

Pay attention to signal arrow direction during wiring; do not reverse, otherwise entire light will not work.

### What are the heat dissipation requirements for small boards?

When using maximum power, blockchain light source requires sufficient heat dissipation, light box must have aluminum heat dissipation back panel.
