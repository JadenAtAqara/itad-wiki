## Product Overview

Aqara Pastel Downlight/Spotlight H1 series is Aqara Pastel series' core downlight/spotlight product for home base lighting, applying latest platform-based quad-color tinted color constant current driver, equipped with customized quad-color COB LEDs and larger size optical lenses.

The device adopts new-generation quad-color mixing technology (customized tinted LEDs + mixing algorithm), supports 1800K-12000K ultra-wide color temperature range and rich tinted color light expression, with light color infinitely close to natural light variation patterns; Ra97 high color rendering index, SDCM &lt;5 color deviation, ten-thousand-level dimming depth, 25000h rated lifespan, significantly superior light quality compared to traditional RGB or dual color temperature solutions.

Software platform developed based on new thing model under Zigbee/Thread dual protocol architecture, accessing Aqara Studio or Matter-compatible third-party ecosystems according to usage environment. Supports static and dynamic scene customization, 0~10s gradient transition, custom lighting transition curves and other advanced configurations.

- This device requires use with Aqara gateway for full functionality support. Certain specific features are only supported in Aqara Studio / Aqara Life App.

### Installation Precautions

:::caution
Installation involves high-voltage work; must be installed by professionals in accordance with electrical codes and product manual.
:::

- This product is for indoor use only; do not use outdoors;
- Pay attention to moisture protection; do not splash water or other liquids onto this product;
- Do not place this product near heat sources;
- Do not attempt to repair this product yourself; this work should be performed by authorized professionals;
- This luminaire is for recessed installation; not suitable for installation inside conduits;
- If external flexible cord or cable of this luminaire is damaged, it must be replaced by manufacturer, its service agent or similarly qualified persons to avoid danger;

## User Guide

### Device Pairing

Device defaults to Zigbee protocol for network joining. After device enters pairing mode, it can be added to Aqara Studio or Aqara Life App for use.

:::tip
When device is not joined to network, upon powering on, light breathes twice and automatically enters pairing mode. Pairing time is 60s. If pairing time is exceeded, device can be power-cycled to re-enter pairing mode.
:::

##### Add to Aqara Studio

According to current protocol used by device, please refer to following documents to complete addition:

| Protocol | Document |
| --- | --- |
| Zigbee | [Zigbee Device Integration Guide](./../../device-integration/zigbee.mdx) |
| Matter | [Matter Device Integration Guide](./../../device-integration/matter.mdx) |

##### Add to Aqara Life App

1. Download Aqara Life App (scan QR code on manual, or search and download from Apple App Store / Google Play).
2. Open App, enter "Home" page then click "+" in upper right corner to enter "Add Device" page, follow App prompts to complete addition.
    

### Firmware Update

You can update device firmware to latest version in Aqara Studio or Aqara Life App before starting use.

| **Platform** | **Operation** |
| --- | --- |
| Aqara Studio | Read [Firmware Update](./../../device-management/firmware-upgrade.mdx), follow prompts to complete update. |
| Aqara Life App | Update device firmware to latest version in App settings page, follow prompts to complete update. |

:::tip
If you integrate device to third-party ecosystem (such as Apple, Google or Amazon, etc.) and cannot get latest firmware, you can pull latest cloud firmware for upgrade by adding device in Aqara Life App and performing two "protocol switch" operations (such as switching Thread to Zigbee, then switching back to Thread).
:::

### Device Reset / Factory Restore

| Operation | Operation Method | Description |
| --- | --- | --- |
| Device Reset | Long press reset button on driver for 5s or more, or cycle power 5 times (keep powered on last time) | Light breathes twice, reset successful. Device only clears network pairing and re-enters pairing state. |
| Factory Restore | Press reset button on driver 10 times, or cycle power 10 times (keep powered on last time) | Light breathes twice, factory restore successful. Device clears all configuration information and re-enters pairing state. |
| Switch Protocol | First remove device in Aqara Life App, then long press reset button for 5s to reset, enter pairing process, click "Switch Protocol" on device pairing screen | Note: Switching protocol is equivalent to factory restore, will clear all device settings and data. |

## FAQ

### How many specifications does Downlight/Spotlight H1 series have?

The currently launched Downlight/Spotlight H1 series is **12W 75mm cutout** specification (4 standard installation models + 1 recessed installation model).

### What installation methods are available?

There are narrow-frame model and recessed model. Recessed model is only available in 36° White Cup SKU (ZNSD20LM).

### Can accessories (such as reflector cups) of Downlight/Spotlight H1 be shared with Downlight/Spotlight T2 Pro?

Yes. Same structure, accessories can be shared.

### How to enter pairing mode?

When device is not joined to network, upon powering on, light breathes twice and automatically enters pairing mode. Pairing time is 60s. If pairing time is exceeded, device can be power-cycled to re-enter pairing mode.

### How to reset device?

Long press reset button on driver for 5s or more or cycle power 5 times (keep device powered on last time). If light breathes twice, reset is successful. After device reset, device only clears network pairing and re-enters pairing state.

### How to factory restore?

Press reset button on driver 10 times or cycle power 10 times (keep device powered on last time). If light breathes twice, factory restore is successful. After factory restore, device clears all configuration information and re-enters pairing state.

### How to switch protocol?

If need to switch protocol during device usage, first remove device in Aqara Life App, then long press device reset button for 5 seconds to reset device, enter pairing process, click "Switch Protocol" on device pairing screen and select required protocol, complete setup according to application instructions.

:::tip
Switching protocol is equivalent to factory restore, will clear all device settings and data.
:::

### Does device support power-off memory function?

Yes, device factory default is "Restore state at power-off". User can change post-power-on state according to own needs in APP's post-power-on state settings, can also set to lights on after power-on, lights off after power-on, and reverse (opposite to state before power-off).

### What is the actual display of color temperature and color palette for light groups composed of different types of lights?

- Dual color temperature lights and colored lights grouped together, only color temperature control within group, when color temperature ranges differ, take intersection;
- Tinted lights and tinted lights grouped together, group has color temperature and tinted color palette;
- Tinted lights and RGB lights grouped together, take RGB color values.
