## Product Overview

The Aqara Panel Hub AX150S is a scene control touch panel designed specifically for B2B customers, used in conjunction with the Aqara Studio platform. Based on the standard 86 wall box form factor, it enables quick replacement of traditional wall switches. It adopts an all-new thing model architecture (not the legacy point-value scheme), supports local network pairing without cloud dependency, and allows flexible configuration of on-screen devices, scenes, and standby content through Studio logic blocks.

The product supports multiple base compatibility (PoE Ethernet base, switch base) and features a built-in Zigbee hub function and temperature & humidity sensor. It supports both Zigbee and Thread dual protocols, with Matter Controller and Thread Border Router capabilities, enabling paired Zigbee sub-devices to connect to third-party Matter ecosystems. It supports dual-band 2.4GHz and 5GHz Wi-Fi 6 wireless networking. The screen supports up to 12 pages and allows custom screensavers and wallpapers.

As a scene control touch panel entry point, it enables linked device control while offering future software and hardware customization extensibility. It supports both close-range touch control and remote APP operation.

## Installation

### Installation Requirements

Installation Location: Recessed wall installation at traditional switch positions (standard 86 wall box), requires live and neutral wire power supply.

Do NOT install in high-humidity environments (bathrooms, kitchens, etc.).

Installation Tool: Screwdriver (for terminal screws).

Accessories: Mounting screws ×2.

### Installation Precautions

Please ensure the main power switch is turned OFF before installation! Connect wiring only when the device is powered off to prevent electrical hazards.

#### PoE Base Version Installation

1. Turn off the main power supply switch;
2. Use a screwdriver to loosen the terminal screws on the back; connect the live wire to the L terminal and the neutral wire to the N terminal;
3. Plug the Ethernet cable into the PoE/LAN port;
4. Verify correct wiring and tighten the terminal screws;
5. Secure the base to the wall junction box using the provided screws (screw torque not to exceed 0.7 N·m);
6. Attach the screen panel onto the base.

#### Switch Base Version Installation

1. Turn off the main power supply switch;
2. Use a screwdriver to loosen the terminal screws on the back; connect the live wire to the L terminal and the neutral wire to the N terminal;
3. Verify correct wiring and tighten the terminal screws;
4. Secure the base to the wall junction box using the provided screws (screw torque not to exceed 0.7 N·m);
5. Attach the screen panel onto the base.

## User Guide

### Quick Setup

#### 1. Power On and Wait for Startup

After connecting to power, the device boots automatically, the screen displays normally, and enters the network pairing prompt page.

#### 2. Add to Aqara Studio

##### PoE Base Version

The PoE Base version supports pairing via Studio or Aqara Life:

- Studio Pairing (Recommended): Ensure that both the M300 and AX150S are on the same local network. After connecting the PoE base to the router via Ethernet, visit the Studio Web page, click "Add Device" under Aqara Hub, discover the device, and then import and add it. For details, see [Aqara Hub Integration](./../../device-integration/aqara.mdx).
- Aqara Life Pairing: Open the Aqara Life APP → Tap "Studio Mode" at the bottom of the login page → Add a new Studio instance (manually enter IP address or domain name) → Log in to Studio → Follow the on-screen guide to complete device setup.

##### Switch Base Version

The Switch Base version pairs via Aqara Life:

- Open the Aqara Life APP → Tap "Studio Mode" at the bottom of the login page → Add a new Studio instance → Log in → Follow the on-screen guide to complete device setup.

#### 3. Configure On-Screen Content via Studio

After the device is paired, configure device cards, scenes, standby screens, and other content through the Studio Web page. Click "Publish" to display the configured content on the screen.

:::tip
Please upgrade the Panel Hub AX150S, the Edge Hub M300, and Aqara Studio to the latest firmware version before use.
:::

## Troubleshooting

### Common Pairing Failures

- Please confirm that the AX150S and the Studio device (e.g., M300) are on the same local network;
- Please confirm that both the device firmware and Studio are updated to the latest version;
- For the PoE Base version, check whether the Ethernet cable is properly connected to the router;
- Check whether the router has Wi-Fi access control enabled, preventing the device from connecting to the network;
- Check whether the router has AP isolation enabled, preventing the phone from discovering the device on the local network;
- It is recommended not to connect to a bridged network;

:::tip
If the device has not completed pairing within 10 minutes, AP and Bluetooth pairing methods will be disabled. You will need to tap the refresh button on the screen or power cycle the device to re-enter the configurable state.
:::

### Factory Reset

Swipe down on the screen to enter the system settings menu. Follow the on-screen prompts to perform a factory reset. Factory reset will clear all function settings and network data.

## FAQ

### What is the main difference between the AX150S and the AX100S?

The AX150S is an upgraded version of the AX100S, with the main chip upgraded to SSD 2351Q, 256MB DDR, added temperature & humidity sensor, support for more base types, and the configuration platform migrated from Aqara Home to Studio, adopting the new thing model architecture.

### Why migrate from Aqara Home to Studio?

Studio is a professional configuration platform designed for B2B customers, offering more flexible new thing model, local configuration, logic blocks, and other capabilities that better suit the professional needs of B2B customers.

### What information can be configured from Studio to the screen?

Scenes and devices, AX150S settings, multiple standby screens, and designed standby screens can all be configured. Some features support batch configuration.

### What is the specific range of LAN control?

When there is no internet connection, the AX150S and its sub-devices can control devices and scenes across gateways within the local network.

### What is the voice assistant support status?

The AX150S device itself does not support voice assistants (no microphone). The audio output is a buzzer only.

### How many pages does the screen support at most?

It supports up to 12 pages.

### What is the difference in pairing methods between the PoE Base version and the Switch Base version?

The PoE Base version supports direct pairing via Studio (automatically discovered after Ethernet connection) as well as Aqara Life pairing — two methods in total; the Switch Base version only supports pairing via Aqara Life.

### What device types does the AX150S support for cards?

Currently supported: Lights, switches, curtains (opening curtains), air conditioning, temperature & humidity sensors, scenes, and energy consumption cards.
