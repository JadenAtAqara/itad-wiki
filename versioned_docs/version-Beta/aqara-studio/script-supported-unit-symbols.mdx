# Unit Names and Symbols Supported by Scripts

The following list comes from the `defaults/units.xml` file loaded by the Studio runtime. For general numeric points in JavaScript scripts, configure `unit` / `units` with one of the unit names below. Studio resolves the unit name and displays the registered symbol in the UI. The system can also match registered unit symbols, but the examples use unit names to avoid formatting differences in characters such as `°C` and `%`.

Common unit names: use `celsius` (displayed as `°C`) for temperature, `percent` (`%`) for humidity, `volt` (`V`) for voltage, `ampere` (`A`) for current, `watt` (`W`) for current power, and `kilowatt hour` (`kWh`) for accumulated energy.
