# Aqara Hub

:::tip
This document is only applicable to the **hub-integrated model** of Aqara Studio.
:::

This guide explains how to connect Aqara Hub to Aqara Studio.

## Add An Aqara Hub

1. In the left sidebar, click **Devices**, select `Aqara Hub` to enter the management page, and click the **Add Device** button.

    ![Add Aqara Hub Devices](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/Devcies-AqaraHubAddDevice.png)

2. Click the **Discover Devices** button. Aqara Studio will search for Aqara Hub devices in the local network.

    ![Discover Aqara Hub Devices](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/AqaraHub-DiscoverDevices.png)

3. Once Aqara Studio finds the Aqara Hub devices, they will appear in the **Discovered Devices** list.

    Select the device(s) you want to integrate and click the **+** button in the middle to add them.

    ![Add Discovered Aqara Hub Devices](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/AqaraHub-AddDevices.png)

4. After a device is successfully added, it will appear in the **Added Devices List** on the right.

    Click the **Done** button to exit the add-device process.

    ![Added Devices List](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/AqaraHub-AddedDevices.png)

5. You will then see the successfully added devices under the Aqara Hub node in **Protocols and Devices** on the left, as well as in the device list on the Aqara Hub management page.

    ![Aqara Hub Device Added Successfully](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/AqaraHub-CheckAddedDevices.png)
