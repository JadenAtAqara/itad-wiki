# Log Management

Select **Log Audit** from the sidebar to access the following seven types of logs, which provide comprehensive data support for system operation and security audits:

- [Device Log](#device-log)
- [Gateway Operation Log](#gateway-operation-log)
- [Link Log](#link-log)
- [User Operation Log](#user-operation-log)
- [Plugin Operation Log](#plugin-operation-log)
- [System Upgrade Log](#system-upgrade-log)
- [Firmware Upgrade Log](#firmware-upgrade-log)

All logs support time filtering and keyword search, meeting daily operation and audit requirements.

:::tip
By default, Aqara Studio displays logs from 00:00:00 to 23:59:59 of the current day. To view historical logs, please manually select the desired time range.
:::

## Device Log

You can view all records of changes in device function point values. You can also filter the logs by device ID, device name, and function point name.

## Link Log 

You can view whether the link channels between Aqara Studio and each protocol (such as Aqara Cloud-M300, Studio Connect-BACnet IP) are operating normally (showing the most recent 500 records). You can also filter the logs by link name.

## User Operation Log

You can view all records of user logins and function usage (showing the most recent 500 records). You can also filter the logs by user name.

## Plugin Operation Log

You can view all operation logs related to Aqara Studio plugins, including operation time, plugin name, type, version, plugin ID, username, and operation details. The logs support filtering and display by type, operation details (such as success or failure of installation, uninstallation, update, etc.), making it convenient to trace plugin usage history and perform operation analysis.

## System Upgrade Log

You can view the time, version number, and result of each system update, which helps track the update history and troubleshoot issues.

## Firmware Upgrade Log

You can view the Aqara device firmware upgrade operations performed through Aqara Studio, including the upgrade time, device ID, device name, upgrade version, and upgrade result, which helps you trace and analyze the update history of device firmware comprehensively.
