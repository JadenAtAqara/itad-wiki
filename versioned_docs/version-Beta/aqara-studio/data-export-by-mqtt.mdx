# Data Export by MQTT

You can use the built-in MQTT broker in Aqara Studio, or integrate your own MQTT broker, to forward device data to third-party platforms and query or control connected devices.

:::tip
This guide will show you how to connect to MQTT and send/receive messages using the MQTTX desktop app.
:::

## What Can You Do with the Data Export by MQTT?

With this feature, you can use all the interfaces listed in [Data Export API v1 - API List](./api-references/data-export-api-v1.mdx#api-list).

## Install the plugin

Please refer to the [Plugin Center](./plugin-center.mdx) documentation:
1. Go to [Aqara Builder](https://builder.aqara.com) to get the `MQTT Export` plugin.
2. Assign it to Aqara Studio.
3. Then go to the **Plugin Center** in Aqara Studio and install the `MQTT Export` plugin.

## Enable the MQTT transfer out service

1. In the left sidebar of Aqara Studio, go to **Plugin Center**, find the `MQTT Export` plugin, and click **Transfer Out**.

    ![Find the MQTT Export plugin in Plugin Center and click Transfer Out](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/MQTT-ClickTransferOut.png) 

2. You will be redirected to the **Developer** page. Please **Enable MQTT Transfer Out**.

    ![Enable the MQTT transfer out service](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/MQTT-EnableMQTTTransferOut.png) 

## Choose a Broker

Choose the broker that fits your needs:
- If you do not have your own MQTT Broker, you can [use the local Broker built into Aqara Studio](#use-the-local-broker).
- If you already have your own MQTT Broker, you can [use a third-party Broker](#use-a-third-party-broker).

### Use the Local Broker

To use the local Broker built into Aqara Studio, select **Local Broker**.

Aqara Studio will connect to this Broker by default.

![Use the Local Broker](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/MQTTExport-SelectLocalBroker.png) 

If the connection status is **Disconnected**, you can choose **... > Connect** to connect manually.

![Connect manually](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/MQTTExport-ConnectToLocalBroker.png) 

### Use a Third-Party Broker

To use your own MQTT Broker:
1. Select **Third-Party Broker** and fill in the following information:

    | Name       | Description                         |
    |----------|----------------------------|
    | HOST       | The address of the MQTT Broker.              |
    | Port     | The port number of the MQTT Broker.            |
    | Client ID | The unique client identifier used for the connection.         |
    | Username    | The username used for authentication.            |
    | Password     | The password used for authentication.              |
    | Enable TLS | Whether to enable TLS encrypted transmission.<ul><li>On: The MQTT Broker address must use the MQTTS protocol;</li><li>Off: Use the MQTT protocol.</li></ul> |

    ![Select a third-party Broker](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/MQTTExport-SelectThirdPartyBroker.png) 

2. (**If TLS is enabled**) Depending on whether you want one-way or mutual authentication, provide the following:

3. Click the *...* button to open the action menu, select **Connect**, and wait until the connection succeeds.

    ![Connect to a third-party Broker](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/MQTTExport-ConnectToThirdPartyBroker.png) 

## Test the MQTT Broker connection

:::tip
- Before you begin, please download and install the [MQTTX](https://mqttx.app/downloads) desktop app, or other MQTT client apps.
- The following steps use MQTTX as an example. Please refer to the official documentation of other MQTT client tools for usage.
:::

1. From the **Developer** page in Aqara Studio above, get all the information needed to connect to MQTT (such as HOST, port, username, and password), as well as the formats for request and response topics.

    The following example uses the local Broker:

    ![Get MQTT connection info](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/MQTTExport-FindInfo.png) 

2. Follow the official MQTTX doc [Getting Started - Connect](https://mqttx.app/docs/get-started#connect), and use the information from the previous step to make the MQTT connection.

    ![Connect via MQTT](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/mqtt-export-2.png) 

3. After you connect, click the **New Subscription** button. Use the **Response Topic Format** shown in Aqara Studio. Replace the ClientID in the topic with the actual ClientID automatically generated by MQTTX to subscribe for response messages.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/mqtt-export-3.png" alt="Subscribe to a response" style={{width: '60%'}} /> 

4. Now, for the subscription you just made, copy the **Request Topic Format** shown in Aqara Studio, replacing the ClientID with your real MQTTX ClientID. Paste this into the Topic field. Then, write a JSON message (based on the request parameters in the [Device Trait API](./api-references/trait-api.mdx) or [Automation API](./api-references/automation-api.mdx)) and send it. You'll get a response back.

    Here’s an example of sending a request to [query the device ID list](./api-references/trait-api.mdx#query-device-spec-configuration):

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/mqtt-export-4.png" alt="Send a request" style={{width: '70%'}} /> 

    And here’s what a sample response looks like:

    ![Receive a response](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/zh/mqtt-export-5.png)
