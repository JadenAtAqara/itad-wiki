# Factory Reset

This article explains how to [perform a factory reset](#perform-a-factory-reset) on Aqara Studio, how to [disable button factory reset](#disable-button-factory-reset), and how to [enable button factory reset](#enable-button-factory-reset).

## Perform a Factory Reset

Depending on your Aqara Studio [deployment model](./overview/introduction.mdx#what-are-the-deployment-models), choose one of the following methods to perform a factory reset:
- For `Hub-Integrated` model, you can factory reset Aqara Studio either via the [Web page](#web-operation) or by pressing the [physical button](#physical-button-operation) on an official Aqara Studio master device (such as Edge Hub M300).
- For `Edge-Deployed` model, you can factory reset Aqara Studio on the [Web page](#web-operation).

### Web Operation

1. Click **Settings** in the left navigation bar. On the settings page, select **About** from the sidebar.
2. Find **System Operation** on the page, click the **Factory Reset** button, and a confirmation box will pop up. In the confirmation box, click **Confirm** to restore Aqara Studio to factory settings.

![Web Operation](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/FactoryReset-Steps.png)

### Physical Button Operation

Please refer to the manual of the official Aqara Studio master device (e.g., [Edge Hub M300](./product-knowledge/gateways/edge-hub-m300.mdx)) to learn how to perform a factory reset on Aqara Studio using button operation.

## Disable Button Factory Reset

For Aqara Studio in `Hub-Integrated` mode, if you do not want others to perform factory reset via the [physical button](#physical-button-operation), you can disable it by following these steps:
1. In the left navigation bar, click **Devices**, select **AqaraHub**, and locate the required official Aqara Studio master device.
2. In the point list of that device, find the **Disable Button Factory Reset** point and set it to `True` to prevent factory reset via the physical button.

![Disable Button Factory Reset](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/FactoryReset-DisableButtonFactoryReset.png)

In this way, when someone attempts to reset Aqara Studio to the factory settings via the [physical button](#physical-button-operation), Aqara Studio will play a voice prompt: "Factory reset is disabled. You can enable it in Aqara Studio settings."

## Enable Button Factory Reset

If you need to allow factory reset via the physical button, refer to the process in [Disable Button Factory Reset](#disable-button-factory-reset) and set the **Disable Button Factory Reset** trait to `False` to enable factory reset via the physical button.

If you forget your password and cannot log in to Aqara Studio, please follow these steps:
1. Contact Aqara support to obtain an SD card containing the reset file.
2. Insert the SD card into the SD card slot of the official Aqara Studio master device (such as the Edge Hub M300).
3. Power off the master device, and then power it on.
4. Wait for the master device to detect and recognize the SD card.
    - If the card matches successfully, the device will automatically enable button factory reset, after which you can press the [physical button](#physical-button-operation) to reset Aqara Studio to the factory settings.
    - If the card does not match and you cannot enable button factory reset, please contact Aqara support again to obtain the correct SD card.
