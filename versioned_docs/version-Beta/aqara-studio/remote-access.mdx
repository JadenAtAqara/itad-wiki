# Remote Access

## Feature Overview

By default, you can only access Aqara Studio within your local area network (LAN). When you need to connect from an external network, you can use **remote access** to securely manage your smart home devices and control systems from anywhere.

## Prerequisites

Before using remote access, please ensure that you have [connected to Aqara Cloud](./cloud.mdx).

## Steps to Access

1. Visit the [Aqara Builder](https://builder.aqara.com) website, and navigate to **Builder Lab** from the left sidebar.

    ![Enter Builder Lab](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/PluginCenter-EnterBuilderLab.png)

2. Select your avatar in the top navigation bar, then select **Studio Manager** from the dropdown list.

    ![Select Studio Manager](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/RemoteAccess-EnterStudioManager.png)

3. Select the **Region** you chose when logging in with your Aqara account during [Cloud Connect](./cloud.mdx).

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/RemoteAccess-SelectARegion.png" alt="Select a region" style={{width: "60%"}} />

4. After entering Studio Manager, switch to the **Studios** tab. Click the Aqara Studio that you want to access remotely.

    ![Connect to Aqara Studio](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/RemoteAccess-SwitchToStudiosAndSelectAStudio.png)

5. In the popup, click **Console** to remotely access the Aqara Studio.

    ![Click the Console button](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/RemoteAccess-ClickConsole.png)

    ![Aqara Studio remote access console](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/RemoteAccess-RealAccess.png)

    :::tip
    You can also use an existing local user account to log in to the remote access address. The permissions granted will be exactly the same as those for local access. For details, please refer to [Local User Management - Local User Roles](./user.mdx#local-user-roles).
    :::

## Share with Other Aqara Users

To invite other Aqara users to remotely access your Aqara Studio, follow these steps:

1. After entering Studio Manager, switch to the **Studio** tab. Click the Aqara Studio that you want to share for remote access.

    ![Connect to Aqara Studio](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/RemoteAccess-SwitchToStudiosAndSelectAStudio.png)

2. In the popup, click the **Share** button.

    ![Click the Share button](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/RemoteAccess-ClickShare.png)

3. In the popup, select the role to assign to the invited user and the expiration time of the invitation link.

    ![Select a role and expiration date](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/RemoteAccess-SelectARoleAndExpirationDate.png)

4. Click **Copy** to share the link with other Aqara users.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/RemoteAccess-CopyTheLink.png" alt="Copy the link" style={{width: "60%"}} />

5. After the invited user clicks the link, they will see a page for requesting access and need to click **Request**.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/RemoteAccess-Request.png" alt="Request access" style={{width: "60%"}} />

6. In Studio Manager, open the Studio details again, view **Studio Member**, find the request, and click **Approve**.

    ![Approve the request](https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-studio/en/RemoteAccess-ApproveRequest.png)

7. The invited user can then see the Aqara Studio under the **Studio Manager > Studio** tab and remotely access it. For details, see [Steps to Access](#steps-to-access).
