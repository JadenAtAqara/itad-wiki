# Disconnect a Studio from the Cloud

Disconnecting a Studio from the cloud removes its cloud connection. Before continuing, verify the Studio and its project so that you do not disconnect the wrong device.

1. Open the target Studio.
2. Find the option to disconnect it from the cloud.
3. Verify the Studio details.
4. Read the explanation of what the change will affect.
5. Follow the on-screen instructions to confirm the disconnection.
6. Check the result.
