# Manage Projects

Projects organize and manage Studios. Every Studio must belong to a project.

## View Projects

1. Open Studio Manager.
2. Confirm the current account, Personal Team, and Region.
3. Open the project list.
4. Find the project you need.
5. Open the project to view its Studios.

## Create a Project

1. Open the project list.
2. Select the option to create a project.
3. Enter the project details.
4. Confirm to create the project.
5. Check that the new project appears in the list.

## Edit a Project

1. Find the project you want to change.
2. Open the project's edit options.
3. Update the available project details.
4. Save your changes.

## Delete a Project

The Default project cannot be deleted like a regular project. You also cannot delete a project that still contains a Studio.

To delete an empty, non-default project:

1. Open the project you want to delete.
2. Select Delete Project.
3. Review the project details and deletion message.
4. Confirm the deletion.

## Move a Studio

Studio Move transfers a Studio from its current project to another project.

1. In Studio Manager, find the Studio you want to move.
2. Open Studio Move.
3. Select the destination project.
4. Verify the current project, destination project, and Studio.
5. Confirm the move.
6. Open the destination project and check the Studio.
