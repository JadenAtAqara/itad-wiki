# Manage Studio Members

Studio members can access and use a specific Studio. Because Application UIs are deployed to Studio members, add the members before deploying a UI.

## Invite a Member

1. Find the target Studio.  
2. Open Studio member management. 
3. Select Invite Member. 
4. Enter the account you want to invite. 
5. Choose Admin or Operator.
6. Verify the account, Studio, and role.
7. Send the invitation.

The invited person can accept or decline. The sender can cancel an invitation that has not yet been accepted.

## Remove a Member

1. Find the member in the Studio member list.
2. Verify the member's account and role.
3. Select Remove Member.
3. Select Remove Member.
4. Confirm the action.
