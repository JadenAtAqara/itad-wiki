# Manage the UI Used by Members

Application UIs are created in Builder Lab and deployed to Studio members. Use Studio Manager to view or change the UI currently assigned to each member.

## View UI Assignments

In UI management, you can view:
* The UIs currently available to the Studio.   
* The members currently assigned to each UI.  
* Members who have a UI assigned.
* Members who do not yet have a UI assigned.

## Assign a UI to Members

1. Open UI management for the Studio.   
2. Select the UI you want members to use.
3. Open member management.
4. Select one or more members.
5. Review the UI currently assigned to each selected member.
6. Save your changes.

## Change or Unassign a Member's UI

* To change a UI, select the UI the member should use and save.
* To unassign a UI, clear the member's selection in member management and save.
* If a UI was deployed to the wrong member, change the UI assigned to that member here.
