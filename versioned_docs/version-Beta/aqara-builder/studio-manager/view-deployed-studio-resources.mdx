# View Deployed Studio Resources

After opening a Studio, use Resources to view related resources and History to view past actions and results.

## View Resources

1. Open the target Studio. 
2. Open Resources.   
3. View the resources currently available in the Studio.
4. Confirm that the resource names and projects are correct.

## View History

1. Open the target Studio.
2. Open History.
3. Find the record you want to review.
4. Open the record to view its details and result.
