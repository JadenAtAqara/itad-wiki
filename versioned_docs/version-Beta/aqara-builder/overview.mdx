# Overview

## What is Builder?

Builder is a set of products for discovering whole-home smart ideas, creating and deploying designs, and managing completed projects. It includes Community, Builder Lab, and Studio Manager.

Whether you want to create a whole-home smart space, design your own solution, or deploy an existing design to a real project, Builder provides the tools you need.

## What can Community, Builder Lab, and Studio Manager do?

| Product | What it does |
| --- | --- |
| Community | Discover and browse whole-home smart content and explore design ideas for different spaces. |
| Builder Lab | Create space plans, scenes, automations, and Application UIs, then deploy them to a Studio. |
| Studio Manager | Manage projects, Studios, Studio members, resources, history, and the UIs assigned to members. |

You can use the three modules separately or together. Find inspiration in Community, complete your design in Builder Lab, and manage real projects in Studio Manager.

## How can Builder help me get started with a whole-home smart space?

Start in Community to explore whole-home smart ideas and design approaches. Then use Builder Lab to create your own space plan from scratch.

If you already have an Aqara Studio and smart devices, you can also sync the devices connected to your Studio into Builder Lab and continue designing with your existing devices.

## What tools does Builder provide for creating a whole-home smart design?

Builder Lab provides two types of design tools: Space Plan and Application UI.

In Space Plan, you can draw the floor plan, add furniture and smart devices, set up light strips and switch controls, and design scenes and automations. In Application UI, you can create interfaces that Studio members can view and control.

## How do I deploy and manage an existing whole-home smart design?

You can deploy a space plan to a Studio. Before deployment, Builder matches the devices in your plan with the actual devices in the Studio.

You can deploy an Application UI to selected Studio members. After deployment, use Studio Manager to view or change the UI assigned to each member and to manage related projects, Studios, members, resources, and history.

## What is the difference between Space Plan and Application UI?

Space Plan covers the floor plan, furniture, device placement, scenes, and automations. It is deployed to a Studio. Before deployment, you must match the devices in the plan with the actual devices in the Studio.

Application UI controls the interface that users see and operate. It is deployed to specific members of a Studio. Device matching is not required, but the members must first be added in Studio Manager.

Space Plan and Application UI are separate modules, so you can create and deploy them independently.
