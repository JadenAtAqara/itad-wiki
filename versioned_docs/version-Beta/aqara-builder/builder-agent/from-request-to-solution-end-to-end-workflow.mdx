# From Request to Solution: End-to-End Workflow

## Full Path

A complete end-to-end spatial intelligence solution design typically follows these steps:

```mermaid
flowchart TD
    A[① Create Project]
    B[② Floor Plan Recognition (Spatial Parsing)]
    C[③ Device Recommendation Agent (First on Stage)]
    D[④ Scene Generation Agent (Second on Stage)]
    E[⑤ Automation Generation Agent (Third on Stage)]
    F[⑥ Generate Solution Package]
    G[⑦ One-click Deploy to Aqara Studio<br/>Installer Uses It]

    A --> B
    B --> C
    C --> D
    D --> E
    E --> F
    F --> G
```

**What each step does:**

1. **Create a project**: Open a new project in Builder Lab, name it, and upload the floor plan
2. **Floor plan recognition**: The Agent completes spatial parsing, converting the floor plan into a semantic model
3. **Device Recommendation Agent**: Generates a device list based on the request (new property recommendations + gap filling for existing properties)
4. **Scene Generation Agent**: Orchestrates one-tap smart scenes (simple / complex flows)
5. **Automation Generation Agent**: Generates condition-triggered automation rules
6. **Generate solution package**: All three Agents work together to output the complete solution file
7. **One-click deploy**: Solution is pushed to Aqara Studio; installers use it immediately


## Quick Start

1. Create a new project in Builder Lab and upload the floor plan
2. Once floor plan recognition is done, click "Activate Agent" — Device Recommendation Agent goes first
3. Enter your spatial needs (e.g., "3 bedrooms, 2 living rooms — I want whole-home lighting control and smart AC")
4. The Agent reads the floor plan, understands the space, and outputs a device recommendation list
5. As needed, switch to Scene Generation or Automation Generation to continue orchestrating
6. Once the solution package is generated, push it to Aqara Studio with one click for installation and use
