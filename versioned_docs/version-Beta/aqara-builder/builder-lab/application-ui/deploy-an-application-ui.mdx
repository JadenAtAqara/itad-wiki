# Deploy an Application UI

An Application UI is deployed to specific Studio members. Device matching is not required.

## Confirm the Members Before Deployment

Before deployment, invite the intended users to the target Studio and manage them in Studio Manager. Only people who have joined the Studio can be selected during UI deployment.

If someone has not joined the Studio, see Manage Studio Members first.

## Select the Studio and Members

1. In Builder Lab, open the Application UI you want to deploy.
2. Start the deployment process.
3. Select the target Studio.
4. Select one or more Studio members who will use the Application UI.
5. Verify the Application UI, Studio, and members.
6. Confirm the deployment.

## What if I deploy a UI to the wrong member?

Go to Studio Manager and change the UI currently assigned to that member under member UI management.
