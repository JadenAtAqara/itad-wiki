# Create and Edit an Application UI

An Application UI organizes the screens that Studio members can see and operate. It is separate from Space Plan, so you can create and deploy it independently.

## Create an Application UI

1. Open Application UI in Builder Lab. 
2. Create or open a UI plan.
3. Create a UI.
4. Start with a blank UI or an official template.
    
## Edit the UI

In the UI editor, you can:
* Add and configure functional components.
* Change component content and screen layouts.
* Create and manage multiple screens.
* Set up navigation between screens.
* Preview and save the UI.

Steps: 
1. Open the UI you want to edit.
2. Create or select a screen.
3. Add the components you need.
4. Adjust the component content and layout.
5. Create other screens and set up navigation as needed.
6. Preview and save the UI.
