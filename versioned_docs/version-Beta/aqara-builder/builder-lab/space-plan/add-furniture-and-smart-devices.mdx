# Add Furniture and Smart Devices

After drawing the main structure, add furniture and smart devices for the intended use of each room. Furniture helps you check whether lights, switches, sensors, and other devices are positioned appropriately.

## Add Furniture

1.  Open the Furniture Library.
2.  Browse or search for the furniture you need.
3.  Add the furniture to the canvas.
4.  Move it to the intended room and position.
5.  Adjust its orientation and other settings as needed.
6.  Check that it does not conflict with walls, doors, windows, or other items.

## Add Smart Devices

1.  Open the Device Library.
2.  Find the smart device you need.
3.  Add the device to the canvas.
4.  Place it in the appropriate room and position.
5.  Adjust its orientation and other editable settings.

When you create a plan from scratch, items added to the canvas are placeholder devices in the plan. When you create a plan with My Devices, you can design with devices synced from the Studio.

## Check Supported Placement Surfaces

Some furniture and device icons display a small symbol in the lower-right corner. This symbol shows where the item can be placed.

Supported placement surface：
- Wall
- Floor
- Ceiling
- Track
- Door
- Window

If an icon has no placement symbol, you can place the furniture or device freely.
