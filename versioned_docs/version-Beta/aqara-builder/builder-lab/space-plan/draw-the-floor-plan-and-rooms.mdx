## Draw the Floor Plan and Rooms

After opening a space plan, draw the main floor plan and room layout before adding furniture and smart devices.

### Main Work Areas

The Space Plan editor includes these main areas:
1.  Canvas: View and edit the floor plan, furniture, and devices.
2.  Drawing tools: Draw walls and other structural elements.
3.  Furniture Library: Find and add furniture.
4.  Device Library: Find and add smart devices.
5.  Properties panel: Change the position and settings of the selected item.
6.  View controls: Zoom, pan, or change the view.

### Draw Walls

1.  Select the wall tool.
2.  Select the wall's starting point on the canvas.
3.  Move the pointer and select the wall's endpoint.
4.  Continue drawing the remaining walls to match the floor plan.
5.  Check that the walls connect correctly and that each room is enclosed as intended.
6.  Before deleting a wall, check whether it contains doors, windows, switches, or other devices. Deleting the wall may affect those items.
