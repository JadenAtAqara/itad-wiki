# Design Scenes and Automations

Scenes and automations let devices perform specific actions in defined situations. You can only create or edit scenes and automations by chatting with the Agent.

## Create a Scene or Automation with the Agent

1. Open Scenes and Automations.    
2. Start a conversation with the Agent.
3. Describe the scene or automation you want in natural language.
4. If needed, provide more details about the devices, triggers, conditions, and actions. 
5. Finish the conversation.
    
When the conversation ends, the system automatically creates and saves the scene or automation. You do not need to confirm or save it manually.

When describing what you want, you can specify:
- What should trigger the scene or automation.
- Whether any conditions must be met.
- Which devices should respond.
- What each device should do.

## Modify a Scene or Automation with the Agent

To modify an existing scene or automation, continue the conversation with the Agent and describe the changes you want.

1. Start a conversation with the Agent.    
2. Specify the scene or automation you want to modify.
3. Describe what you want to replace, add, or remove.
4. Finish the conversation.

When the conversation ends, the system automatically updates and saves the scene or automation.

## View an Automation Workflow

After creating an automation, you can view its Workflow.

1. Open the list of created scenes and automations.
2. Select the automation you want to view.
3. Open its Workflow.
4. Review its triggers, conditions, device actions, and execution flow.

A Workflow is for viewing an automation only. You cannot create or edit an automation directly in the Workflow. To make changes, return to the Agent conversation.
