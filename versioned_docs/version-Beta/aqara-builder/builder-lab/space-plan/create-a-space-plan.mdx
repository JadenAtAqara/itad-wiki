# Create a Space Plan

A space plan brings together the floor plan, furniture, smart devices, scenes, and automations. When you create one, choose Create from Scratch or Create with My Devices.

## Create from Scratch

Choose this option if you do not have the physical devices yet or want to finish the design before preparing the devices.

1.  Open Builder Lab.
2.  Select the option to create a space plan.
3.  Select Create from Scratch.
4.  Enter the plan name and other details.
5.  Confirm to create the plan and open the Space Plan editor.

## Create with My Devices

Choose this option if you already have a Studio with connected devices. You can sync its device list to the editor and design with those devices.

You can connect to either of the following:

- A Remote Studio that is connected to the cloud and belongs to your current account.   
- A Local Studio on the same local network as your device.
    

Steps:

1.  Open Builder Lab.
2.  Select the option to create a space plan.
3.  Select Create with My Devices.
4.  Select Remote Studio or Local Studio.
5.  Review the list of devices connected to the selected Studio.
6.  Confirm the device sync and create the plan.
    
Before using a Local Studio, make sure the Studio has been set up and that the device running Builder Lab is on the same local network.

## Use the Plan with Another Studio

Creating a plan with My Devices does not permanently link the plan to the source Studio.

- If you deploy the plan back to the source Studio, the system automatically matches devices that were previously deployed.
- If you deploy the plan to another Studio, the system performs device matching again for the target Studio.
- After automatic matching, you can change any match manually.
