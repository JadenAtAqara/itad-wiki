# Add Switches

Place each switch in the correct position, then choose which devices each button will control.

### Add a Switch

1.  Open the Device Library.
2.  Find the switch you want to use.
3.  Add the switch to the room.
4.  Place it in the correct room and on the correct wall.
5.  Make sure the number of buttons meets your design needs.

### Choose the Devices Controlled by a Switch

1.  Select a switch that you have placed.    
2.  Open Switch-Controlled Devices.
3.  Select the button you want to configure.
4.  Choose one or more devices for the button to control.
5.  Configure the remaining buttons as needed.
6.  Review the control assignments and save.

Keep the following in mind:
- One button can control multiple devices.
- After you choose the first controlled device for a button, you can only add other devices of the same category.
- If the first controlled device is an Aqara smart device, you can only add other Aqara smart devices.
- If the first controlled device is a third-party smart device, you can only add other third-party smart devices.
- The same device can be controlled by multiple buttons.
