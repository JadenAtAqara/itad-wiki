# Add Light Strips

Choose the position and coverage of each light strip based on the actual room.

1. Open the Device Library.
2. Find the light strip you want to use.  
3. Add the light strip to the room.
4. Adjust it to match the planned installation position.
5. Check that it is in the correct room and position.
6. Save the design.

When positioning a light strip, consider the walls, ceiling, furniture, and actual installation requirements.
