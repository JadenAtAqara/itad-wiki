# Getting Started with Builder: Projects and Agent

This document explains how to sign in to Aqara Builder, create, search for and switch projects, understand the project workspace, and use Aqara Agent to submit requirements, attach files, check generated output and handle failures.

## Sign In and Select a Project

### Sign in to Aqara Builder

1. Visit [Aqara Builder](https://builder.aqara.com). Select a region, then sign in to your Aqara account with a password or verification code.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-builder/en/visit-aqara-builder-and-login.png" alt="Sign in to Aqara Builder" style={{ width: '80%' }} />

2. After signing in, you enter **Home**. Check the account and region first. Projects and resources in different environments must be verified separately.

### Create, search for and switch projects

From the left sidebar, open **Project**. On this page you can [create a project](#create-a-project) or [search for an existing project](#search-for-a-project).

<img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-builder/en/enter-project.png" alt="Open the Project page" style={{ width: '80%' }} />

#### Create a project

To create a new project:

1. Select **New Project**.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-builder/en/new-project.png" alt="New Project" style={{ width: '80%' }} />

2. Enter the name, description and region, then select **Create**.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-builder/en/new-project-info.png" alt="New project information" style={{ width: '80%' }} />

3. Open the project from the project list.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-builder/en/enter-new-project.png" alt="Open the new project" style={{ width: '80%' }} />

    Check the project name at the top left of the page.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-builder/en/check-project-name.png" alt="Check the project name" style={{ width: '80%' }} />

#### Search for a project

To search for an existing project, find the search box on the **Project** page, enter the project name, and select search.

<img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-builder/en/search-project.png" alt="Search for a project" style={{ width: '80%' }} />

#### Switch projects

To work on another project, expand the left sidebar and switch from the **Recent** project list, or return to the project list and select another project.

<img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-builder/en/switch-projects.png" alt="Switch projects" style={{ width: '80%' }} />

## Understand the Project Workspace

After you select a project, you see that project's workspace. The areas are:

<img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-builder/en/workspace.png" alt="Project workspace" style={{ width: '80%' }} />

| No. | Area | Purpose |
| --- | --- | --- |
| 1 | Aqara Agent | Describe requirements, provide references, and inspect generation progress and results. |
| 2 | Space Plans | Create floor plans, furniture layouts, device points and spatial designs. |
| 3 | App Dashboard | Create and preview the project's mobile control interface. |
| 4 | Studio | View the project's on-site Studio and resources. |
| 5 | Members | Manage project collaboration and project information. |

## Start and Continue Work with Agent

### Start from Home or a business page

You can submit a requirement to Aqara Agent from **Home** or from a project's **workspace**.

Keep the following in mind:

- When you send a requirement from Home, check the project name that will be used.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-builder/en/ask-from-home.png" alt="Submit a requirement from Home" style={{ width: '80%' }} />

- When working on an existing plan or dashboard, open the target object before sending the request.
- If the requirement involves rooms, devices, expected behavior or constraints, state them specifically. For example: “Create a mobile dashboard for the living room and entryway of the current home, showing lighting states and a Homecoming scene.”
- To provide a floor plan or reference images, select **+ Attachment** in the input area, choose the files, confirm that the upload has finished, and then send the requirement.

    <img src="https://itad-aqara-docs-1300889962.aqara.com/dev/img/aqara-builder/en/attach-files.png" alt="Attach files" style={{ width: '80%' }} />

### Check output and handle failures

1. Read the progress, tool results and failure messages shown by Aqara Agent.
2. After generation, open the corresponding business page and inspect the actual output item by item.
3. For further changes, name the target and explain what to retain and what to modify.
4. If generation fails, first check the current project, object, attachments and service messages, then use the stop or retry controls available on the page.

Conversations can continue when you switch modules within the same project. Recheck the context after you switch projects. Check Agent's response, the actual output and the saved result separately.
